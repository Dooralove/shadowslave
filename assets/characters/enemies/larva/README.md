# Larva corpse asset

- **Source:** “Bloodspike Horror Creature” by **Purple.Point** on Sketchfab.
- **URL:** https://sketchfab.com/3d-models/efdc13de41904163aed0319b74c3d305
- **License:** CC BY 4.0 (Sketchfab “CC Attribution”). Attribution is required in release credits.
- **Original:** 261.7k triangles, 130.7k vertices, 25-bone humanoid rig, Idle clip.
- **This version:** three primitives joined, decimated to 28,785 triangles / 32,175 vertices; 25-bone rig and Idle clip preserved; scaled to ~1.03 m; +Y forward in Blender (Godot −Z); generated normal/roughness maps and regraded albedo.
- **Used by:** `scenes/locations/caravan_site/larva.tscn`, `scenes/enemies/larva_enemy.tscn`, `larva_arena`.
- **Source scene:** `source/larva_corpse_source.blend` (packed maps, Godot ignores `source/` via `.gdignore`).
