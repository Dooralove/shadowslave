# Carapace Scavenger

Project-owned procedural enemy asset.

- **Model:** `carapace_scavenger.glb` — 31-bone crab rig, 5 clips, LOD0/1/2 5 940 / 2 726 / 1 034 tri.
- **Builder:** `source/build_carapace_scavenger.py` (Blender 5.1, no external models or textures).
- **Scene:** `scenes/enemies/carapace_enemy.tscn`.
- **AI:** `scripts/combat/carapace_enemy.gd` (separate from TestEnemy).
- **Data:** `resources/combat/enemies/carapace_scavenger.tres`, `resources/combat/attacks/carapace_claw.tres`.
- **Canon:** crab-like carapace, segmented legs, two claws, bone spikes, no human face/eyes; 2.5–3.5 m class.
