# Show repair plan — S00–S15 campaign

Статус: **в работе**. Цель — довести кампанию до состояния, которое можно показывать без «пустоты», плавающих объектов и сломанной камеры. Это alpha-качество, не финальный арт.

## P0 — блокеры показа

1. **Парк / улица.** Вернуть землю, дорогу, тротуары и фасады; убрать чёрную пустоту перед скамейкой.
2. **Полицейский участок.** Добавить интерьер лобби/допросной, чтобы здание не было пустой коробкой.
3. **Модели NPC.** Заменить оставшиеся mannequin-плейсхолдеры на доступные модели/архетипы; выставить по сценам.
4. **Текст.** Проверить все `.tscn/.gd/.tres` на double-encoded строки; исправить.
5. **Горный король.** Привязать к скале/уступу, убрать «парение».
6. **Камера повозки.** Вынести из кузова; проверить кадр при столкновении.
7. **Плавающие деревья/камни/маркеры/следы.** Найти audit-скриптом и починить.
8. **Прыжок и удары.** Включить в прологе/кампании (сделано), проверить в живом сценарии.
9. **NPC-стейджинг.** Ветеран, Шифти, Герой, Учёный — поставить по beat sheet, не «в углу».
10. **Визуальная подача действий.** Для ключевых beat добавить позы/жесты/камеру, а не только текст.
11. **Квестовые цели.** Обновлять objective после фляг, ветерана, боя, пещеры.
12. **Миникарта.** Добавить map definitions для park/station/containment/void или скрывать виджет без карты; проверить все локации.
13. **Маркер в воздухе.** Привязать к земле/объекту.
14. **Подъём.** Расширить проходимую полосу, убрать «щель».
15. **Коллизии/границы.** Закрыть дыры, убрать выход за границы и «затекстурье».
16. **Пещера / «выжить».** Сделать вход, врагов/события и понятный objective.
17. **Финальные проверки.** Campaign tour, route/boundary, full GUT, captures.

## Принципы

- Не ломать M1/tech/Academy.
- Не удалять существующие сцены/ассеты без замены.
- После каждого блока — целевой тест + скриншот.
- В конце — full GUT, campaign tour, push clean branch.
