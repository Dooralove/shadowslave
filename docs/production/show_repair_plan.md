# Show repair plan — промо-сборка (пролог → демо-фрагмент)

Статус: **в работе**. Цель — довести кампанию до состояния, которое можно показывать без «пустоты», плавающих объектов и сломанной камеры. Это alpha-качество, не финальный арт.

- **Конец показа (промо-сборка):** `labyrinth_first_fragment` → карточка «КОНЕЦ ДЕМОНСТРАЦИОННОГО ФРАГМЕНТА» (`scenes/campaign/post_nightmare_finale.tscn`). Это весь реализованный на данный момент путь.
- **Полная цепочка показа:** `campaign_entry` (пролог B01–B16) → Первый Кошмар S01–S15 → `police_precinct` (M1, P05) → `academy_approach` → `academy_gate` → `academy_campus` → `academy_sleeper_center` → `black_sea_platform` → `tide_descent` → `labyrinth_first_fragment` → финальная карточка демо.
- **S15 — веха, а не конец показа:** карточка «ПЕРВЫЙ КОШМАР ЗАВЕРШЁН» (`finale_arrival.tscn`) закрывает Первый Кошмар; кнопка «Продолжить: после Кошмара» ведёт в M1.
- Вручную хвост (M1 P05→Z10, tech Z11→Z18, Академия) **не пройден** — до этого показ считается альфа-показом.
