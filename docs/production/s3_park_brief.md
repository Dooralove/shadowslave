## 1. Целевое настроение

**«Пятно ржавчины в стерильном кадре».** Холодное, чистое, дорогое утро, которое не замечает худого подростка на старой скамейке.

- Чистый, правильный, слегка бездушный район: светлый композит, стекло, ровная плитка, ухоженная искусственная зелень (материалы — SECONDARY, «белая монотонность, искусственные деревья ярких цветов»).
- Отфильтрованный воздух: мягкая дымка, которая съедает дальние башни, но не ближний план (CANON: фильтры в богатых районах; степень дымки — ИНТЕРПРЕТАЦИЯ).
- Санни и скамейка — единственное старое, тёплое по цвету и неровное в кадре. Всё остальное холодное, гладкое, новое.
- Тишина вокруг скамейки, движение вокруг неё: прохожие идут потоком и не останавливаются.
- Мрачность здесь не в темноте, а в отчуждении. Темнее станет в лобби и изоляторе — парк должен быть самой светлой сценой пролога, чтобы было куда падать.

## 2. План пространства

Оси как в текущей сцене: −Z — к участку (север), скамейка в (0, 0, 4) смотрит на участок.

```
                 дальний план: башни в дымке, 80–300 м (силуэты)
          ┌───────────── средний план: фасады квартала 25–60 м ─────────────┐
          │      ███ УЧАСТОК: тяжёлый объём, бронепанели, узкие окна ███     │
          │  столбики-ограждения ··· ВХОД (свет) ··· столбики                │ z ≈ −19
          │═══════ дальний тротуар ══════════════════════════════════════════│
          │  ─ ─ ─ проезжая часть  ─ ─ ─   ║║ ПЕРЕХОД ║║   ─ ─ ─ ─ ─ ─ ─ ─   │ z ≈ −11
          │═══════ ближний тротуар: основной поток прохожих ════════════════│ z ≈ −7
          │   [кадка]        ╲ диагональная дорожка к переходу              │
          │  [дерево]  газон  ╲          [дерево]       [кадка + дерево]     │
          │                    ╲                                             │
          │   поток ←──────────── поперечная дорожка ──────────────→ поток   │ z ≈ 2
          │                       ┌──────────┐                              │
          │          [дерево]     │ «карман» │ [урна]                        │ z ≈ 4
          │                       │ СКАМЕЙКА │                               │
          │   ▓▓ подпорная стенка / клумба-бордюр, за ней цоколь башни ▓▓   │ z ≈ 7
          └──────── задник: стеклянный цоколь жилой башни, экран ───────────┘
```

Решения:

1. **Скамейка в «кармане»** — небольшой нише сбоку от поперечной дорожки, на отдельном пятне старой плитки. Санни сидит вне потока, поток обтекает его. Это пространственная метафора, а не канонический факт (ИНТЕРПРЕТАЦИЯ).
2. **Диагональная дорожка** от поперечной дорожки к пешеходному переходу. Она становится ведущей линией и разбивает симметрию. Переход выровнен по двери участка: маршрут читается без маркеров.
3. **Участок смещается из центра кадра** на треть (повернуть фасад или сдвинуть вход вдоль улицы, не меняя z двери). В кадре со скамейки участок оказывается справа по правилу третей, а слева открывается глубина улицы.
4. **Улица работает как граница двух зон**: светлый ухоженный парк и тёмный тяжёлый объём участка. Переход — пороговый момент.
5. **Задник за скамейкой**: цоколь жилой башни со стеклом и светлым композитом, на нём большой экран с пейзажем (SECONDARY: «экраны с пейзажами и пропагандой»). Это закрывает тыл при обзоре сидя и даёт подсветку со спины (контровой свет на Санни).
6. **Боковые выходы улицы** не заглушены: улица уходит в дымку влево и вправо, глубина по оси X. Бортики, а не забор.
7. **Площадь парка остаётся ~20×16 м.** Канон: «маленький парк». Увеличивать нельзя — плотнее проработать то, что есть.
8. Опционально (SECONDARY + ИНТЕРПРЕТАЦИЯ): эстакада магнитного трамвая на среднем плане поперёк улицы — сильный горизонтальный элемент глубины. Решение за вами.

## 4. Свет и материалы

### Свет (ИНТЕРПРЕТАЦИЯ на основе `art_direction.md`: «рассеянное холодное небо сквозь дымку»)

- **Солнце:** низкое утреннее, сбоку-сзади относительно взгляда со скамейки, холодно-белое, приглушено дымкой (энергия ~1,0–1,5, мягкие длинные тени).
- **Идея света:** карман со скамейкой лежит в тени цоколя башни, а улица и фасад участка освещены. Санни сидит в тени и уходит из тени к свету входа (ИНТЕРПРЕТАЦИЯ, без претензии на канон).
- **Небо:** `ProceduralSkyMaterial` холодной гаммы (HDRI — только после согласования загрузки CC0).
- **Заполнение:** окружение от неба, без «плоского» ambient-цвета, как сейчас.
- **Акценты:** свет входа участка (холодный голубой), экран за спиной Санни (контровая подсветка), пар кофе. Окна участка — холодные или тёмные, без тёплого жёлтого.
- **Туман:** обычный туман по глубине для дальнего плана + слабый объёмный туман в пределах ~40 м, плотность растёт с расстоянием. Ближний план чистый.
- **Пост-обработка:** AgX (вопрос 6 плана среза), SSAO включить, glow только для эмиссии, без motion blur. Цветокоррекция — лёгкий холодный сдвиг теней.

### Палитра

| Роль | Цвет | Где |
|---|---|---|
| Основа (70 %) | Светлые холодные серые, белёсый композит | Фасады, плитка, бордюры |
| Среднее (20 %) | Сине-серые тени, тёмный асфальт, графит участка | Улица, участок |
| Неестественная зелень | Приглушённый бирюзовый/холодно-зелёный | Кроны и газон |
| Тёплый акцент (< 5 %) | Ржавый оранжево-коричневый, тёплый пар | Скамейка, стаканчик |

### Материалы и состояние поверхностей

| Материал | Состояние |
|---|---|
| Композит фасадов и кадок | Чистый, матовый, видны тонкие технологические швы, лёгкая неравномерность отражения |
| Стекло | Холодное отражение неба и соседних зданий (ReflectionProbe) |
| Плитка | Ровная; едва заметная вытертость вдоль основных потоков; старый участок плитки под скамейкой |
| Асфальт | Тёмный, чистый, свежая разметка |
| Металл скамейки | Слои: старая краска → сколы → ржавчина → вытертый до металла край сидения; ржавые потёки на плитке |
| Урна | Новый композит и металл |
| Искусственная зелень | Слегка глянцевый пластик, без вариаций цвета — именно «слишком правильная» |

Следы использования, которые допустимы в чистом районе: вытертость плитки по траектории потока, следы уборки (свежая влажная полоса у бордюра — опционально), потёртое сидение скамейки. Больше ничего.

## 5. Этапы создания в Blender

Blender 5.1.1 уже установлен. Новые инструменты не нужны. Модели собираются **скриптами Blender в фоне** (как сборка Санни в S2): это воспроизводимо, но означает, что лучше всего получаются твёрдые городские формы (плитка, бордюры, фасады, скамейка, кадки), а органика ограничена. Искусственные деревья по канону геометричны — это удобно.

| Этап | Результат | Стоп-точка |
|---|---|---|
| **S3.1 Блок-аут** | Объёмы в реальном масштабе по плану выше: карман, дорожки, улица, переход, участок, задник, слои фона. Серые материалы, но уже финальный свет и туман. 6 контрольных кадров | **Скриншоты → ваше согласование композиции** |
| **S3.2 Герой-объекты** | Ржавая скамейка (≈3–5 тыс. треугольников, LOD), урна, стаканчик; материалы со слоями ржавчины и краски | Скриншоты крупных планов |
| **S3.3 Модульный набор** | Плитка и бордюры, кадки, искусственное дерево (Geometry Nodes, 2–3 вариации), фонарь, столбик, фасад участка из модулей | Скриншоты среднего плана |
| **S3.4 Фон и доводка** | Фасады квартала, башни, мосты, экран; финальная настройка света, тумана, LUT; замер производительности | Полный отчёт и сравнение до/после |

Технические правила:

- Исходники в `assets/environments/park/source/` (скрипты `.py` + `.blend`), экспорт в `.glb` по одному на объект или модуль. `.blend` и `.glb` — в LFS, скрипты и `.tscn` — нет.
- Масштаб 1 юнит = 1 м, ось вперёд согласована с Godot, начало координат у основания объекта.
- UV2 для запекания света (lightmap UV в Blender или генерация в Godot при импорте).
- Коллизии простыми формами (суффикс `-colonly` или отдельные `StaticBody3D`), не по визуальному мешу.
- LOD: Godot генерирует автоматически при импорте; для фона — отдельные упрощённые меши.
- **Текстуры:** по умолчанию — процедурные материалы Blender с запеканием в 1K/2K. Процедурщина быстро выглядит «компьютерно», поэтому рекомендую отдельно согласовать загрузку 6–8 CC0-материалов с Poly Haven или ambientCG (бетон, плитка, асфальт, окрашенный ржавый металл, композит). Без вашего разрешения ничего не скачиваю.

## 6. Интеграция в Godot

Тот же принцип, что в S2: **вариант без правки кода и с полным откатом.**

1. Новая сцена искусства `scenes/slice/locations/park/park_art.tscn`: геометрия, свет, `WorldEnvironment`, фон. Отдельно от игровой логики.
2. Сцена-вариант `park_street_art.tscn`, наследник `park_street.tscn`:
   - прячет `Geometry`, `Skyline`, `Lights` (и выключает у CSG `use_collision`);
   - добавляет инстанс `park_art.tscn`;
   - переопределяет только позиции `Shots/*` (новый первый кадр) и при необходимости камеру.
   - `Spawns`, `Markers`, `Interactables`, `Triggers`, `Props/CoffeeCup`, `Commuters` остаются — `park_street.gd` и режиссёр не меняются.
3. Корень пролога-варианта для проверки (как `prologue_poc.tscn`). Основной пролог переключается только после вашего визуального одобрения.
4. **GI:** локация статичная и небольшая → **LightmapGI** (запекание непрямого света от солнца и неба) + реальные тени солнца. SDFGI — только запасной вариант, если запекание не даст нужного качества. `ReflectionProbe` для стекла и улицы.
5. Тени солнца: дистанция ~40 м, 2–3 сплита; фон без теней.
6. Окклюзия: фасады квартала как окклюдеры (`OccluderInstance3D`), если замер покажет пользу.
7. Новая коллизия совпадает по высотам с текущей (пол на y = 0), чтобы спавны и посадка не съехали. Проверка — существующий тест прохождения пролога.

## 7. Критерии визуальной приёмки

Набор из 6 фиксированных кадров (первый кадр, сидя вперёд, сидя назад, урна, середина пути, от перехода назад), один и тот же для «до» и «после».

- [ ] Маршрут к участку читается за 2 секунды без подсказок.
- [ ] Санни и скамейка отделяются от фона по яркости или цвету в каждом кадре со скамейкой.
- [ ] Читаются три плана глубины: передний, средний, дальний в дымке.
- [ ] Тёплый акцент один — скамейка, стаканчик. Других тёплых пятен нет.
- [ ] Район читается как богатый и чистый; скамейка — как инородный старый объект.
- [ ] При обзоре сидя на 360° нет пустых стен и обрезанной геометрии.
- [ ] Масштаб правдоподобен: двери 2,1 м и выше, Санни 1,65 м ниже прохожих, скамейка в стандартной высоте сидения ~0,45 м.
- [ ] Нет видимых дефектов: z-fighting, висящих объектов, растянутых текстур, щелей между модулями, протечек света.
- [ ] Всё, что не канон, помечено в документах как интерпретация; ни одной новой сюжетной детали.
- [ ] Производительность: см. п. 8.

## 8. Риски и ограничения для RTX 3060 Laptop

**Бюджет локации** (цель — 60 FPS в 1080p, `art_direction.md`):

| Параметр | Бюджет |
|---|---|
| Время кадра GPU в парке | ≤ 10 мс (запас под персонажа, UI, пост-обработку) |
| Треугольников в кадре | ≤ 1,5 млн |
| Draw calls | ≤ 1 500 (модули — через общие материалы, повторы — инстансы) |
| Текстуры локации | ≤ 300 МБ VRAM; 2K только для скамейки и плитки, остальное 1K, фон 512 |
| Динамические источники с тенями | Только солнце |

**Риски:**

| Риск | Что делаю |
|---|---|
| Процедурные материалы выглядят «компьютерно» | Запросить разрешение на CC0-материалы; ставка на свет и композицию, а не на текстуры |
| Органика (кроны) из скриптов выглядит грубо | Канон даёт искусственные деревья — делаем их нарочито геометричными |
| Искусственная зелень «неестественного цвета» уходит в мультяшность | Приглушённая насыщенность, проверка в кадре на этапе S3.1 |
| Объёмный туман дорог на ноутбуке | Малая дальность (~40 м), низкое разрешение тумана; дальний план — обычный туман |
| LightmapGI: UV2, швы, время запекания | Простые формы, проверка на блок-ауте; запасной вариант — SDFGI с низкими настройками |
| Переполнение деталями | Список объектов фиксирован в п. 3; новые объекты — только с обоснованием |
| Неканонические решения | Помечены как интерпретация; спорные (трамвай, экран, смещение участка) — на ваше решение |
| Объём работы | Стоп-точка после каждого этапа S3.1–S3.4 |
