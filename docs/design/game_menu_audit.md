# Аудит и доработка меню игры в духе «Ведьмака 3»

Дата: 2026-11-02  
Область: интерфейс игрока, бестиарий, глоссарий, карта, медитация  
Статус: реализовано в рабочем дереве; финальный ручной проход — **NOT TESTED**

## 1. Референс

За основу взята композиция экрана «Глоссарий» из The Witcher 3:

- верхний ряд категорий с крупной золотой заливкой выбранной вкладки;
- подтабы внутри раздела;
- список статей слева и пергаментная карточка описания справа;
- блок «Последние статьи»;
- краткая сводка игрока в правом верхнем углу;
- нижняя строка подсказок управления.

Переносится **структура чтения интерфейса**, а не механики. Алхимия, зелья, уровни, опыт и вес в проект не добавляются: они прямо запрещены каноном (`docs/design/11_combat_system.md`, `docs/design/12_inventory_economy_and_consumables.md`, `docs/design/09_skill_tree_and_progression.md`).

## 2. Что было до изменений

### 2.1. Меню игрока

- `scripts/ui/player_menu_system.gd` — autoload, открывал `RpgMenuPrototype` по `C`.
- `scenes/ui/rpg_menu_prototype.tscn` — отдельный прототип с верхними вкладками:
  «Инвентарь», «Персонаж», «Аспект / навыки», «Памяти», «Задания», «Торговля».
- `scripts/ui/rpg_menu/*` — экраны инвентаря, персонажа, аспекта, заданий, торговли и заглушка «Памяти».
- Меню было модальным, ставило игру на паузу, освобождало курсор, закрывалось по `Escape`/`C`.

### 2.2. Карта

- `MapSystem` — autoload, открывал отдельный `MapScreen` по `M`.
- `MapScreen` — `CanvasLayer` на весь экран, не являлся частью окна меню.
- `Карта мира` и `Карта региона` уже работали, но визуально были вторым окном.

### 2.3. Бестиарий

- `BestiaryEntry` (`scripts/campaign/bestiary_entry.gd`) и три `.tres` в `resources/campaign/bestiary/`.
- `NightmareRunState` хранил открытые записи и включал их в snapshot.
- `CampaignGuide` открывал записи по событиям и добавлял их в журнал.
- Отдельного экрана бестиария не было: записи показывались только строкой в журнале заданий.

### 2.4. Чего не хватало

| Пробел | Следствие |
|---|---|
| Нет глоссария | Бестиарий, обучение, персонажи и места не собраны в один справочник |
| Нет отдельного экрана бестиария | Игрок не может листать записи, видеть закрытые статьи и слабости |
| Карта — отдельное окно | Нарушает требование «одно окно» |
| Нет сводки игрока | Не видно, сколько записей открыто и на каком событии находится игрок |
| Нет медитации | Нет спокойного экрана с текущей целью и точкой возврата |
| «Памяти» — заглушка | Раздел остаётся честным черновиком, но не связан с меню |
| Нет тестов нового UI | Глоссарий и встроенная карта не проверялись |

## 3. Канон и ограничения

- **Алхимия, зелья, крафт, ремонт, вес, уровни и опыт не добавляются.** В текущем сегменте их нет; вводить их ради сходства с референсом нельзя.
- **Верхняя сводка** поэтому показывает не «деньги / вес / уровень / опыт», а реальные для проекта величины: количество предметов, открытые записи бестиария, текущее событие и прогресс по событиям.
- **Рюкзак** остаётся демонстрационным набором `RpgDemoSession`; это ограничение зафиксировано в `DECISIONS` и не маскируется под канонический инвентарь.
- **Бестиарий** читает те же `.tres`, которые наполняет отдельная сессия контента. UI не создаёт лор и не дублирует записи.
- **Закрытые записи** не отдают название, текст и слабость: в списке стоит `???`, в карточке — подсказка об условии открытия.

## 4. Что сделано

### 4.1. Верхняя навигация

- Восемь категорий: `ГЛОССАРИЙ`, `ПАМЯТИ`, `РЮКЗАК`, `КАРТА МИРА`, `ЗАДАНИЯ`, `ПЕРСОНАЖ`, `УМЕНИЯ`, `МЕДИТАЦИЯ`.
- Выбранная вкладка заливается тёплым золотом, иконка и подпись становятся тёмными; остальные вкладки приглушены.
- Иконки взяты из существующего набора `assets/ui/rpg_menu/icons/` (`book`, `amulet`, `armor`, `map`, `scroll`, `cloak`, `dagger`, `herb`).
- `Торговля · ДЕМО` осталась отдельной кнопкой и явно помечена как демонстрационная.

### 4.2. Сводка игрока

Строка над шапкой показывает:

- `ПРЕДМЕТЫ` — суммарное количество предметов из `NightmareRunState.ITEM_IDS`;
- `ЗАПИСИ` — открытые записи бестиария / всего записей;
- `СОБЫТИЕ` — текущий beat (`P01…N26`);
- тонкий индикатор прогресса по числу событий.

Сводка обновляется по сигналам `bestiary_unlocked`, `item_changed`, `flag_changed`, `state_reset`, `state_restored`, `beat_changed`.

### 4.3. Глоссарий

Новый экран: `scripts/ui/rpg_menu/rpg_glossary_screen.gd`, `scenes/ui/rpg_menu/glossary_screen.tscn`.

- Подтабы: `БЕСТИАРИЙ`, `ОБУЧЕНИЕ`, `ПЕРСОНАЖИ`, `МЕСТА`.
- Слева — «Последние статьи» (до четырёх записей, открытых в этом сеансе) и полный список выбранного подтаба.
- Справа — пергаментная карточка: категория, название, метаданные, текст, слабость/повадка, источник.
- **Бестиарий** читает `CampaignGuide.get_bestiary_entries()`; если autoload недоступен, загружает `resources/campaign/bestiary/*.tres` напрямую. Открытость проверяется через `CampaignGuide.has_bestiary_entry()` или `NightmareRunState.has_bestiary()`.
- **Обучение** собирает «Правила Кошмара» из `resources/campaign/journal/`, остальные записи журнала (кроме бестиария) и справку «Управление», построенную из `InputMap`.
- **Персонажи** читает `resources/campaign/glossary/characters/*.tres`, когда отдельная сессия добавит записи. Папка создана, формат описан в её `README.md`; пока показывается честный пустой экран.
- **Места** берёт `MapAtlas` и ограничивает список текущим регионом; вне игры — регионом Первого Кошмара. Это не даёт глоссарию раскрывать места будущих глав.

### 4.4. Карта внутри меню

Новый экран: `scripts/ui/rpg_menu/rpg_map_screen.gd`, `scenes/ui/rpg_menu/map_screen.tscn`.

- Использует существующие `MapAtlas`, `MapCanvas` и live-маркер игрока.
- Показывает общую карту мира и карту региона, список регионов/мест и карточку описания.
- `MapSystem` по `M` сначала пытается открыть вкладку «Карта мира» единого меню; полноэкранный `MapScreen` остаётся запасным путём и публичным API для тестов.

### 4.5. Медитация

Новый экран: `scripts/ui/rpg_menu/rpg_meditation_screen.gd`, `scenes/ui/rpg_menu/meditation_screen.tscn`.

- Показывает текущее событие, активную цель, точку возврата и предметы при себе.
- Справа — «Правила Кошмара» на пергаменте.
- Кнопка «Вернуться к точке» использует существующий `FallRecovery.recover()` и доступна только при наличии игрока и назначенной точки. Это не новая система сохранений.

### 4.6. Встраивание в игру

- `PlayerMenuSystem` обрабатывает `C` (персонаж) и `I` (рюкзак), открывая **одно и то же** окно на разных категориях.
- `MapSystem` обрабатывает `M` и переключает уже открытое меню на карту; если меню недоступно, открывает прежний полноэкранный `MapScreen`.
- `Escape` закрывает окно и восстанавливает паузу/курсор.
- Старый отдельный `InventoryPrototype` в арене больше не открывает второе окно по `I`: он передаёт клавишу в `PlayerMenuSystem` и остаётся сценой-витриной/запасным путём.
- Подсказка в `scenes/levels/combat_arena.tscn` обновлена: `C — меню · I — рюкзак · M — карта`.

### 4.7. Визуальная тема

В `RpgMenuTheme` добавлены:

- `WitcherTab` / `WitcherSubTab` — золотая заливка выбранной вкладки;
- `ParchmentPanel` / `ParchmentInset` — светлая карточка статьи;
- `ParchmentTitle`, `ParchmentBody`, `ParchmentMuted`, `ParchmentHint`, `ParchmentOverline`, `ParchmentButton`;
- `SummaryCaption` / `SummaryValue` — компактная сводка игрока.

Палитра и системные шрифты остались прежними; новых бинарных ассетов нет.

## 7. Ограничения и backlog

1. **Инвентарь, персонаж, аспект и торговля остаются демо-данными.** Их нельзя считать каноническим инвентарём; для подключения нужен каталог предметов и StatusSheet.
2. **«Памяти» — черновик.** Каталог Memories/Эхо ещё не создан.
3. **«Персонажи» пусты.** Папка `resources/campaign/glossary/characters/` и README с форматом созданы; записи должен добавить отдельный контент-сеанс.
4. **Торговля** противоречит канону текущего сегмента; в релизе её нужно скрыть или заменить контекстным действием.
5. **Карта мира** по-прежнему показывает регионы в разработке; это существующее поведение `MapScreen`, не менялось.
6. **Иконки и шрифты** — существующие SVG и системные шрифты; финальный арт-пасс не выполнялся.
7. **Локализация** не вынесена в ключи; тексты на русском в коде/ресурсах.
8. **Полный GUT** зелёный после `--import`; stale UID в untracked park-GLB требует импорта, иначе GUT считает предупреждения ошибками. Это не дефект меню, но сборка должна проходить импорт перед прогоном.

## 8. Правки по результатам аудита

После первого прохода аудита точечно исправлено:

1. **Кнопка «Карта региона»** в `RpgMapScreen` теперь disabled не только при отсутствии текущего региона, но и для региона в разработке — нажатие больше не выглядит доступным, хотя ничего не делает.
2. **Счётчик открытых записей** в верхней сводке читает `NightmareRunState.get_bestiary_ids()` напрямую, а не пересчитывает каждую запись через `CampaignGuide`. Если `CampaignGuide` временно недоступен, счётчик остаётся верным.
3. **Папка персонажей** `resources/campaign/glossary/characters/` создана с `README.md` и `.gitkeep`: отдельная контент-сессия получает явный формат `.tres` и место для записей.

Проверка после правок: целевой набор `test_rpg_menu_glossary` + `test_player_menu_system` + `test_map_system` — **39/39**, 833 assert, exit 0; полный GUT — **554/554**, 6746 assert, exit 0. Остальные пункты раздела 7 — контент, арт или ручные проверки, а не дефекты меню; в этой сессии они не правятся.
