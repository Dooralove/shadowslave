# Audits — индекс отчётов

Все отчёты получены и сведены в `../MASTER_AUDIT.md`.

## Правила

- Один отчёт — один файл.
- Имя файла: `NN_<direction>.md`; эквиваленты приняты, если явно указаны.
- Отчёт не меняет игровые файлы.
- Все утверждения о runtime — только после фактического запуска; иначе **NOT TESTED**.
- Ссылки на файлы и строки обязательны.
- Не перезаписывать чужой отчёт; комментарии — в `NN_<direction>_td_notes.md`.
