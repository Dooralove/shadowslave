# UI/UX дизайн демонстрационного прохождения

**Дата:** 2026-11-02  
**Область:** M1 (участок → академия → Чёрное море → спуск → Лабиринт) и общие компоненты Первого Кошмара.  
**Статус:** проектные решения и реализованный минимум. Полный ручной проход — **NOT TESTED**.

---

## 1. Цели

1. Игрок всегда понимает: **где он, что делает, что изменилось и что будет дальше**.
2. Интерфейс не превращает приключение в чтение таблиц: HUD отвечает на один вопрос за раз.
3. Каждое действие имеет видимую обратную связь: цель, предмет, урон, прилив, ошибка.
4. UI — часть мира: тёмный камень, бронза, коралл, пергамент; никаких «веб-панелей».
5. Всё, что выглядит интерактивным, работает; всё, что не работает, честно помечено или скрыто.

---

## 2. Принципы

| Принцип | Реализация |
|---|---|
| Один экран — один модальный слой | Меню, карта, рюкзак и пауза взаимоисключающие |
| HUD у краёв | Центр кадра остаётся для мира и боя |
| Цель — одна строка | Текущая цель не превращается в список из пяти задач |
| Прогресс — числом | `1/3`, `0/3`, а не только полоска |
| Обратная связь — коротко | Тост 2–4 с, вспышка 1.3 с, подсказка 8–10 с |
| Ошибка — объяснение | «Низкие проходы закрыты» вместо «Нельзя» |
| Клавиатура — первый класс | Стрелки, Enter, Esc, подписи горячих клавиш |
| Масштаб — глобальный | 1600×900 canvas-items, `expand` |

## 3. Сетка и типографика

### 3.1. Базовая сетка

- Reference: **1600×900** (растягивается на 1280×720 … 4K).
- Safe margin: **24 px** от краёв; крупные панели — 32–48 px.
- Верхняя зона: здоровье/выносливость (слева), подсказка (центр), мини-карта и цель (справа).
- Нижняя зона: быстрые предметы (слева), взаимодействие и субтитры (центр), тост и подсказки управления (справа).
- Модальные окна: центр, ширина 1080–1200 px, максимум 760 px по высоте.

### 3.2. Шкала

| Роль | Размер | Вариация |
|---|---|---|
| Заголовок экрана | 36–42 | `ScreenTitle` |
| Заголовок карточки | 26–30 | `ScreenTitleSmall` |
| Тело | 15–17 | `BodyLabel` / `BodyLargeLabel` |
| Мета и подписи | 11–13 | `TinyMutedLabel` / `MicroLabel` |
| Оверлайн | 9–11, разрядка | `OverlineLabel` / `SectionLabel` |
| Числа прогресса | 12–13 | `BronzeLabel` |

Правило: **не больше трёх размеров в одной панели**. Иерархия задаётся цветом и отступами, а не зоопарком кеглей.

## 4. Полный состав HUD

`GameplayHud` подключён к Лабиринту и ко всем семи пост-Кошмарным сценам M1. В M1 до Лабиринта сцена выставляет цель через `CampaignGuide.set_external_objective`; в Лабиринте — из `QuestSystem`; в Первом Кошмаре — из `CampaignGuide`.

### 4.0. Композиция по референсу (актуально с 2026-11-03)

Расположение элементов приведено к референсу The Witcher 3; стиль остаётся
кораллово-бронзовым. Подробный разбор — `docs/design/hud_reference_analysis.md`.

| Элемент | Позиция (1600×900) | Источник |
|---|---|---|
| Здоровье/выносливость | верхний левый, 20,20–380,150 | `CombatHud` + `VitalsBar` |
| Контекстное действие | под виталами, 24,158–380,186 | `InteractionPromptUI` |
| Полоса врага | верхний центр, 650,20–950,80 | `CombatHud.EnemyPanel` |
| Мини-карта и компас | верхний правый, 1386,24–1576,236 | `HudMinimap` + `MapSystem.minimap_snapshot()` |
| Трекер задания | правый столбец, 1240,242–1576,342 | `ObjectiveLine` |
| Прилив | правый столбец, 1240,352–1576,430 | `TideIndicator` |
| Быстрые предметы | нижний левый, 24,746–274,876 | `HudQuickItems` + `NightmareRunState` |
| Субтитры | нижний центр, 380,768–1220,872 | `SubtitleUI` |
| Тост | нижний правый, 1240,670–1576,730 | `QuestToast` |
| Подсказки управления | нижний правый, 1240,746–1576,876 | `HudControlHints` + `InputMap` |

Мини-карта показывает локальные `MapFeature` и видимые `MapMarker`; маркер
задания — золотой. Быстрые предметы читают реальные счётчики
`provisions`/`water_skin`/`torch`, а не рисуют фиктивные числа. Время суток и
погода не добавляются: в проекте нет соответствующей системы, а прилив уже
имеет отдельный индикатор.

### 4.1. Правый столбец — цель

```
ЗАДАНИЕ 01
Первый день на берегу: Дойти до первой развилки
[прогресс 0/1, если цель счётная]
```

- Источник: `QuestSystem` (Лабиринт) → `CampaignGuide` (M1 через `set_external_objective`, Первый Кошмар).
- При смене: 1.3 с подпись «ЦЕЛЬ ОБНОВЛЕНА», затем возврат к коду задания.
- При завершении: «ЗАДАНИЕ ЗАВЕРШЕНО» цветом успеха.
- Ширина: 336 px, выравнивание по правому краю; перенос строк, не обрезка.
- Не перекрывает мини-карту сверху и индикатор прилива снизу.
- Для активного задания в правом трекере показывается название задания, а не только код.

### 4.2. Верхний центр — подсказка/обучение

- Временная строка, max 2 строки, 8–10 с.
- Используется для обучения, сюжетных реплик и предупреждений.
- Не дублирует субтитры и не остаётся после события.
- Приоритет: сюжетная подсказка > обучение > бытовой совет.

### 4.3. Правый столбец — прилив

```
ПРИЛИВ РАСТЁТ
[====------] 42%
ДО ПРИЛИВА 00:31 · ИЩИТЕ ВЫСОКИЙ ПУТЬ
```

- Виден только при наличии `TideController`.
- Расположен под трекером задания, чтобы не спорить с мини-картой.
- Цвет: синий — отлив, золотой — рост, красный — высокая вода.
- За 20 с до подъёма: предупреждение и звук.
- При высокой воде: «НИЗКИЕ ПРОХОДЫ ЗАКРЫТЫ».
- Ширина 336 px.

### 4.4. Верхний левый — здоровье и выносливость

- Появляется в бою, после урона/траты и на 4 с при первом появлении.
- Числа: `Санни · 74 / 100`.
- Цвет: зелёный > 60%, золотой 30–60%, красный < 30%.
- Красная вспышка по краям экрана при получении урона.
- «КРИТИЧЕСКОЕ СОСТОЯНИЕ» пульсирует, но не закрывает центр.
- Вне боя при полном запасе скрыт, чтобы не занимать кадр.
- Контекстное действие (`E — Идти`) показывается под виталами.

### 4.5. Под виталами — взаимодействие; центр низа — диалог

- Подсказка `E — Забрать Азурный клинок` появляется только при фокусе; строка живёт под виталами.
- Субтитры: нижняя треть, ширина ~840 px, не более 4 строк.
- Имя говорящего — золотым, текст — светлым, счётчик `2 / 5` — приглушённым.
- Клик по панели и `E / Space / Enter` — далее.
- Во время диалога ввод движения блокируется, но HUD остаётся читаемым.
- Барки Санни — отдельная панель выше субтитров, исчезает сама.

### 4.6. Нижний правый — тосты и подсказки управления

- Тосты: подбор, задание, награда, ошибка/предупреждение.
- 2.4 с + 0.3 с fade; не более одного тоста одновременно; новый заменяет старый.
- Ниже тостов — постоянные подсказки `InputMap` (`Shift`, `E`, `M`).
- Подсказки не перекрывают субтитры и быстрые предметы.

### 4.7. Мир — маркеры и компас

- Доступные `Interactable` в радиусе 12 м: маленький ромб; в фокусе — кольцо и `E`.
- Текущая цель: золотой ромб с дистанцией; за экраном — стрелка у края.
- Маркеры скрываются в паузе, меню, карте, рюкзаке, Море Души и диалоге.
- Не более 8 маркеров одновременно; дальние — приглушены.

### 4.8. Верхний правый — мини-карта

- Круглая карта 190×212 px: локальные `MapFeature`, видимые `MapMarker`, стрелка игрока.
- Север вверху; компас N/E/S/W и насечки — бронза.
- Данные — `MapSystem.minimap_snapshot()`, без второго MapSystem.
- Подпись региона — под картой; маркер задания — золотой ромб.
- Карта обновляется 8 раз в секунду; `SubViewport` рендерится по требованию.

### 4.9. Нижний левый — быстрые предметы

- Три строки: хлеб (`provisions`), вода (`water_skin`), факел (`torch`).
- Иконка, количество, короткое имя; данные — `NightmareRunState`.
- Обновляется по `item_changed`; нулевые позиции приглушены.
- Это витрина переносимых припасов, а не второй инвентарь.

### 4.10. Нижний правый — подсказки управления

- `Shift` — ускориться, `E` — взаимодействие, `M` — карта.
- Клавиши читаются из `InputMap`, поэтому переназначение не оставляет ложных подсказок.
- Кейкапы — тёмная пластина с бронзовым кантом; текст — костяной.
- Подсказки обновляются раз в секунду, если привязки изменились.

## 5. Цели и квестовые состояния

### 5.1. Модель

| Состояние | Журнал | HUD |
|---|---|---|
| Нет задания | Пустая карточка/подсказка | Строка скрыта |
| Доступно | `◇ ДОСТУПНО` | Не показывается, пока не взято |
| Активно | `◆ АКТИВНО` + прогресс | Текущая цель и `N/M` |
| Завершено | `✓ ЗАВЕРШЕНО` | «ЗАДАНИЕ ЗАВЕРШЕНО» 3 с, затем следующее |
| Провалено | Не используется в демо | — |

### 5.2. Обновление

1. `QuestSystem.quest_progressed` → пересчёт строки и прогресса.
2. `QuestSystem.quest_completed` → тост и строка завершения.
3. `tracked_quest_changed` → HUD переключается на выбранное задание.
4. `CampaignGuide.objective_changed` → fallback для Первого Кошмара.
5. Idle-уточнения не перебивают активное задание Лабиринта.

### 5.3. Журнал

- Заголовок: «ЗАДАНИЯ», источник «ЖУРНАЛ КАМПАНИИ».
- Левая колонка: текущая цель, сводка, кнопка «Следить за целью».
- Центр: список записей, активная/доступная/завершённая.
- Правая: описание, прогресс, цели, заметка, состояние.
- Кнопка tracking доступна только для активного задания.
- DEMO-каталог не используется как источник; при отсутствии живых записей показывается пустое состояние.

## 6. Диалоги

### 6.1. Композиция

```
[САННИ]                                      2 / 5
Мы больше не в цепях. Но это не значит, что мы свободны.
E / Space / Enter — далее
```

- Панель не на весь экран; максимум 45% высоты.
- Клик по панели — далее.
- Таймерные реплики идут сами; клик по панели не ломает таймер.
- Голос и субтитры синхронны; при отсутствии VO субтитр остаётся.
- Барки не смешиваются с сюжетными репликами.

### 6.2. Ошибки и пустые данные

- Пустая последовательность завершает диалог без зависания.
- Неизвестный говорящий показывается как id, а не «null».
- Длинный текст переносится, не обрезается.
- Диалог не ставит игру на паузу, но блокирует движение и атаку.

## 7. Маркеры интерактивных объектов

| Тип | В мире | Подпись |
|---|---|---|
| `Interactable` доступен | Маленький ромб | `E — <prompt>` внизу |
| В фокусе | Кольцо + `E` | Нижняя подсказка |
| Подбираемый предмет | Ромб + свечение | Тост после подбора |
| Текущая цель | Золотой ромб + дистанция | Строка цели |
| Цель за экраном | Стрелка у края | Дистанция |
| Враг | Полоса HP (CombatHud) | Имя и HP |

Правила:
- Не показывать маркеры сквозь стены и за камерой.
- Не показывать маркеры в модальных окнах.
- Не превращать все объекты в одинаковые золотые точки: цвет и форма различают типы.

## 8. Карта и навигация

### 8.1. Данные

- `labyrinth_first_fragment.tres`: 18 зон, маршрут, 17 маркеров, `world_bounds = Rect2(-1470, -160, 1520, 320)`.
- Регион `region_forgotten_shore`: `ACTIVE`, одна локация, placement `(800, 200)`, `1.0 px/m`, область `1600×400`.
- Маркеры используют `world_position`; подобранные/убитые скрываются через `hide_when_flag`.
- Текущая цель подсвечивается кольцом; target_id переводится в marker_id таблицей.

### 8.2. Экран

- Заголовок: «КАРТА МИРА».
- Если у текущей сцены нет играбельного региона, открывается **локальная карта сцены** с её реальной геометрией (участок, академия, Чёрное море, спуск).
- Строка цели под заголовком.
- Карта региона: геометрия зон, маршрут, маркеры.
- Правая колонка: список мест, группировка по локациям, карточка описания.
- Кнопки: «Общая карта», «Карта региона».
- Колесо — зум, drag — сдвиг, клик по маркеру — подробности.
- Игрок — стрелка в кольце; «вы здесь» на общей карте.
- Флаги игры передаются в `show_local`; карта не показывает уже собранное.

### 8.3. Соответствие миру

- Границы и маршрут взяты из blockout-таблицы зон.
- Ключевые маркеры сверены с узлами сцены: `FirstFight (0,0)`, `Camp (—100,—5)`, `Cliffs (—1400,0)`, `AzureBlade (0,1)`, `Nephis (—65,0)`.
- Карта — схема, а не коллизия; финальная живопись — отдельный арт-проход.

## 9. Меню паузы

### 9.1. Открытие

- `Esc` только в 3D-сцене с игроком.
- Не открывается, если открыто меню персонажа, карта, рюкзак или Море Души.
- Если другое окно только что закрылось этим же Esc, пауза не открывается 180 мс.
- При открытии: `tree.paused = true`, курсор видим; при закрытии — восстановление.

### 9.2. Состав

```
ПАУЗА                                      ESC — ПРОДОЛЖИТЬ
ТЕКУЩАЯ ЦЕЛЬ
Первый день на берегу: Дойти до первой развилки
ЗАДАНИЕ 01
──────────────────────────────────────────────────────────
01 ПРОДОЛЖИТЬ        │  МИР ЖДЁТ
02 ТЕКУЩАЯ ЦЕЛЬ      │  Цель и состояние сохранены...
03 НАСТРОЙКИ         │  [ПРОДОЛЖИТЬ]
04 УПРАВЛЕНИЕ        │
   В ГЛАВНОЕ МЕНЮ    │
   ВЫЙТИ ИЗ ИГРЫ     │
```

- Настройки: общая громкость, музыка, эффекты, окружение, голоса, интерфейс,
  субтитры звуков, моно-сведение, динамический диапазон, полноэкранный режим, сброс.
- Управление: секции «Движение», «Бой и взаимодействие», «Интерфейс», «Служебные»;
  переназначение клавиш/мыши/геймпада, Backspace — очистить, Esc — отмена, сброс в project.godot.
- Выход в меню и из игры — с подтверждением.
- Focus: первая кнопка при открытии; стрелки/Enter; Esc — закрыть.

## 10. Обучение и подсказки

### 10.1. Первые 25 секунд Лабиринта

1. Через 1.4 с: `WASD — движение · мышь — обзор · Shift — бег`.
2. Через 9.5 с: `E — взаимодействие · C — меню · M — карта · Esc — пауза`.
3. При первом приливе: `Прилив закрывает нижние проходы...`.

### 10.2. Правила

- Одна подсказка за раз.
- Автоскрытие 8–10 с.
- Сюжетная подсказка отменяет обучающую.
- Не повторять после первого показа в сессии.
- Не перекрывать цель и субтитры.

### 10.3. Что не делаем

- Не показываем туториал поверх диалога.
- Не блокируем ввод на время туториала.
- Не пишем «нажмите кнопку, чтобы продолжить» на каждой реплике.

## 11. Предметы, награды, ошибки

### 11.1. Подбор

- Тост: `Азурный клинок отзывается...` / `Осколок души +1`.
- Иконка/название предмета — в журнале и рюкзаке; в HUD достаточно текста.
- Повторный подбор не создаёт дубль (флаг).

### 11.2. Награды

- `QuestToast` показывает `Награда: ...` из `QuestReward.describe()`.
- Награда выдаётся один раз (`mark_quest_reward_claimed`).
- Валюта и Памяти не занимают слоты рюкзака.

### 11.3. Ошибки и предупреждения

| Ситуация | Сообщение |
|---|---|
| Низкий проход закрыт | «Прилив закрыл низкий проход. Ищите высокий путь.» |
| Нет ключа/предмета | «Нужен предмет: <название>.» |
| Нет цели | «Сначала выберите активное задание.» |
| Сохранение/настройки | «Не удалось сохранить настройки.» |
| Опасность | Красная вспышка + тост, но не модальное окно |

Правило: ошибка никогда не блокирует игру модальным окном, если это не выход/подтверждение.

## 12. Управление

| Действие | Клавиша |
|---|---|
| Движение | W / A / S / D |
| Бег / блок | Shift |
| Прыжок / уклонение | Space |
| Удар | ЛКМ |
| Взаимодействие | E |
| Далее в диалоге | E / Space / Enter |
| Меню персонажа | C |
| Рюкзак | I |
| Карта | M |
| Статус Заклятия | Tab |
| Море Души | V |
| Пауза / закрыть | Esc |
| Перезапуск | R |
| Навигация в меню | ↑ ↓ ← →, Enter |

Правила:
- Одна клавиша — одно действие; конфликт `E` решается контекстом (диалог > взаимодействие).
- Esc закрывает верхний модальный слой; не открывает сразу второй.
- Подсказки клавиш берутся из InputMap, а не дублируются вручную.
