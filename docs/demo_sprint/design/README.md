# Design — единый дизайн-план и контракты

Здесь лежат только решения Technical Director, обязательные для всех чатов.

## Документы

| Файл | Назначение | Статус |
|---|---|---|
| `00_DEMO_SCOPE_AND_CONTRACT.md` | демо-стержень, границы, P0/P1/stretch, контракты систем | действует |
| `01_INTEGRATION_PLAN.md` | порядок сборки, зависимости, точки freeze | после консолидации |

## Правило

Если отчёт чата противоречит этому каталогу, прав каталог до момента, когда TD обновит решение. Изменение архитектуры без записи здесь не принимается.

## Термины

- **Стержень** — обязательный маршрут S00–S15.
- **P0** — без этого демо не принимается.
- **P1** — улучшение, не блокирует.
- **Stretch** — только после зелёного P0.
- **Freeze** — файл нельзя менять без TD.
