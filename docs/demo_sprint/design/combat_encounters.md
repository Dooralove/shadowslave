**Дата:** 2026-11-02  
**Автор:** Chat 05 — Lead Combat & Enemy AI Engineer  
**Статус:** проект для M1-демо (пост-Кошмарная цепочка → Лабиринт).  
**Связанные документы:** `docs/design/11_combat_system.md`, `docs/design/level_brief_labyrinth_first_fragment.md`, `docs/demo_sprint/design/00_DEMO_SCOPE_AND_CONTRACT.md`, `docs/demo_sprint/audits/05_combat_enemy_ai.md`.

## 0. Принципы

1. **Один враг — один урок.** Карапакс учит читать замах и уклоняться; личинка — быстрый контакт; Горный Король — подготовка и отступление, а не прямой размен.
2. **Не количество, а роль.** В демо нет «толпы ради толпы»: 1 учебный карапакс, 3 в стае, 2 на мосту. Всего 6 противников на 1,5 км.
3. **Читаемость важнее разнообразия.** Один и тот же замах карапакса должен читаться с 8–10 м; красное кольцо/свечение дублирует позу, а не заменяет её.
4. **Игрок всегда может отказаться.** Стая Z13 и пара Z14 — побочные бои; основной маршрут можно пройти, не убивая всех.
5. **Каждый бой заканчивается.** Смерть врага отключает атаку, коллизию и квестовый кредит; игрок не «добивает труп».
6. **Никаких скрытых one-shot.** Урон только в окне, окно совпадает с видимым контактом, у игрока есть 0,4–0,9 с на реакцию.

## 1. Роли противников

| Противник | Роль | Стиль | Что проверяет игрок |
|---|---|---|---|
| **Раненый карапакс** | Учебный / pressure | Медленный scuttle, один удар клешнёй, долгий замах | Понять замах, уклониться, ударить в ответ |
| **Карапакс-падальщик** | Pressure / flanker | Боковой scuttle, рывок, клешня | Держать дистанцию, не дать окружить |
| **Личинка** | Skirmisher | Быстрый бросок, процедурный замах | Не стоять на месте, бить после выпада |
| **Горный Король** | Boss / cinematic threat | Медленный, огромный, ломает укрытие | Подготовка, укрытие, отступление, а не убийство |
| **Тестовый гуманоид** | Legacy / sandbox | Прямой chop | Только арена/тесты, в демо не спавнится |

### 1.1. Чего в демо нет

- Ranged-врага (лучник/охотник) — нет дальней угрозы.
- Controller-врага (слизь/зона) — нет контроля пространства.
- Elite (Центурион) — нет боя, меняющего правила.
- Poise/stagger/knockdown — враг не сбивается с ног.
- Добивания/execute — нет контекстного финишера.
- Дружественного AI (Нефис/Кассия/Эхо) — только маркеры.

**Stage 3–5:** групповой токен атак и weak spot hurtbox реализованы; ручной прогон E02/E03 остаётся **NOT TESTED**.

## 2. Боевые профили

### 2.1. Раненый карапакс (E01)

| Параметр | Значение |
|---|---|
| HP | 65 |
| Урон | 18 (стандартная клешня; `carapace_wounded` 14 — вариант для песочницы) |
| Замах | 0,95 с |
| Окно | 0,25 с |
| Recovery | 1,20 с |
| Дистанция атаки | 2,0 м |
| Скорость | 1,6 м/с |
| Роль | учебный, Z03 |

**Поведение:** медленно идёт к игроку, у пня делает замах, бьёт клешнёй. Не догоняет убегающего дальше 14 м. После смерти роняет клешню и оставляет тело.

**Телеграф:** красное кольцо на земле + подъём корпуса + разворот клешни. Игрок должен успеть отойти в сторону.

**Почему 65 HP:** 5–6 ударов P1-кулаком (12) — короткий учебный бой; 5–6 ошибок игрока — смерть. Это не «мешок HP».

**Stage 3–5:** `carapace_wounded_e01.tres` (65 HP, 18 урона, `0.95` замах, `1.6` скорость) используется `WoundedScavenger` через A05 `spawn_profile` по существующему `QuestKillCredit.enemy_tag`; E02/E03 остаются на стандартном профиле.

### 2.2. Карапакс-падальщик (E02/E03)

| Параметр | Значение |
|---|---|
| HP | 95 |
| Урон | 18 |
| Замах | 0,85 с |
| Окно | 0,25 с |
| Recovery | 1,05 с |
| Дистанция атаки | 2,1 м |
| Скорость | 2,1 м/с |
| Роль | pressure/flanker |

**Поведение:** идёт к игроку «крабьим» зигзагом (scuttle), при сближении делает рывок и щелчок клешнёй. При потере цели возвращается в Idle; при застревании делает боковой обход, после трёх неудач отпускает цель на 2 с.

**Телеграф:** кольцо + подъём корпуса + раскрытие клешни. Направление фиксируется в начале замаха — уклонение в сторону работает.

**Слабость:** фланг и спина; в лоб панцирь не даёт бонуса, но и не блокирует урон полностью (в демо нет armor).

### 2.3. Личинка

| Параметр | Значение |
|---|---|
| HP | 55 |
| Урон | 14 |
| Замах | 0,65 с |
| Окно | 0,20 с |
| Recovery | 0,95 с |
| Дистанция | 1,35 м |
| Скорость | 2,3 м/с |

**Поведение:** быстро ползёт, приподнимается, откидывается и бросается вперёд. После выпада замирает на восстановлении — окно для удара. Реакция на урон — короткое сжатие, не сбивающее замах.

### 2.4. Горный Король (босс-сцена)

| Параметр | Значение |
|---|---|
| HP | 600 (сцена) |
| Урон | 25 |
| Телеграф | 1,10 с |
| Windup | 0,35 с |
| Окно | 0,20 с |
| Recovery | 1,40 с |
| Пауза между атаками | 4,50 с |

**Поведение:** DORMANT → CHASE → TELEGRAPH → ATTACK → RECOVERY. В засаде его цель — не убить игрока, а заставить уйти в укрытие и каньон. `BLOCKED` не даёт бесконечно толкаться в стену; `RETREAT` — сценарный.

**Телеграф:** рёв, красное кольцо, долгий замах. Окно урона начинается после 0,35 с windup и закрывается на 0,55 с; видимый удар — 0,433 с.

### 2.5. Тестовый гуманоид

Оставлен только для `combat_arena`/старых тестов. В демо-Лабиринте не спавнится: его chibi-силуэт и `2H_Melee_Attack_Chop` не соответствуют канону Забытого берега.

### 2.6. Зоны поражения

| Атака | Смещение/досягаемость | Радиус сферы | Комментарий |
|---|---|---:|---|
| Санни, P1 кулак | `reach 0.9` от `MeleeAttack` | 0.7 | попадает в карапакса на 2,1 м |
| Санни, KayKit меч | `reach 1.0` | 0.8 | `Slice_Diagonal` |
| Раненый/стандартный карапакс | узел `-1.15`, `reach 1.35` | 1.0 | плюс рывок 0.5 м в активном окне |
| Личинка | `reach 0.95` | 0.75 | процедурный выпад 0.42 м |
| Тестовый гуманоид | `reach 1.1` | 0.8 | legacy |
| Горный Король | `reach 2.4` | 1.4 | плюс корпус 1.0 м |

Зоны — сферы, без sweep/line-of-sight. Удар может задеть цель за тонкой стеной; для демо это принято, для финала нужен `ShapeCast3D`/LOS.

## 3. Сценарии демонстрации

### E01. Первый бой у пня (Z03)

| Этап | Содержание |
|---|---|
| Вход | Игрок выходит из Z01 на развилку, видит пень и кости |
| Обнаружение | Раненый карапакс выползает от пня, кольцо замаха |
| Бой | 5–6 ударов, 2–3 уклонения; блок — запасной вариант |
| Ошибка | Игрок стоит в лоб — получает 18–36 урона, но не умирает |
| Победа | Труп, квест `first_blood`, доступ к Azure Blade |
| После | Тишина, цель обновляется, можно идти дальше |

**Зачем:** проверить весь цикл — замах, окно, урон, смерть, квест, HUD.

### E02. Стая в охотничьих угодьях (Z13)

| Этап | Содержание |
|---|---|
| Вход | Широкая равнина, кости, три карапакса на маркерах |
| Обнаружение | Первый карапакс замечает игрока, остальные подтягиваются |
| Бой | Игрок разделяет группу, использует массы и дистанцию |
| Ошибка | Стоять в центре — три атаки подряд, guard break, смерть |
| Победа | 3 кредита `carapace`, квест `hunt_pack`, 6 осколков |
| После | Можно обойти; награда — ресурс, не ключ |

**Проблема:** групповых токенов нет; три карапакса могут атаковать одновременно. P1 — добавить 1–2 токена и задержку 1,0–1,5 с между атаками.

### E03. Костяной мост (Z14)

| Этап | Содержание |
|---|---|
| Вход | Узкий мост, два карапакса на выходе |
| Бой | Пространство не даёт обойти; блок/уклонение и удар в узком месте |
| Победа | 2 кредита `bridge_carapace`, квест `bridge_stand`, 4 осколка |
| После | Мост свободен, путь к убежищу |

**Зачем:** проверить бой в ограниченном пространстве и завершение пары.

### E04. Засада Горного Короля (sandbox/cinematic)

Не входит в основной маршрут. Сцена `ambush_site` проверяет телеграф, укрытие и отступление. Убийство не является целью демо.

### E05. Арены

- `combat_arena.tscn` — одиночный карапакс, HUD, победа/поражение; используется для отладки.
- `larva_arena.tscn` — личинка.
- `combat_course.tscn` — песочница 1 раненый + 2 личинки + 2 карапакса; нужна для проверки всех типов без загрузки 1,5 км.

**Правила размещения:**

- После боя — тишина и пространство для обыска.

## 5. Баланс и время

| Бой | HP врагов | Ударов игрока (12) | Ожидаемое время | Ошибок до смерти |
|---|---:|---:|---:|---:|
| E01 | 65 | 6 | 15–25 с | 5–6 |
| E02 | 285 | 24 | 45–75 с (с разделением) | 2–3 |
| E03 | 190 | 16 | 30–50 с | 3–4 |

**Правила:**

- Обычный враг не должен жить дольше 15–20 с при правильной игре.
- E02 — исключение как групповая сцена; если бой длится дольше 90 с, это плохой бой.
- Ошибка стоит 18 HP; 100 HP хватает на 5 ошибок.
- Блок пропускает 30% урона, но тратит stamina; 3 удара подряд ломают guard.
- Уклонение — основной ответ; i-frames 0.30 с (текущий `combat_settings.tres`), замах карапакса 0.85–1.10 с.
- Никаких one-shot без телеграфа.

### 5.1. Azure Blade

Сейчас клинок — предмет/квест, но не меняет боевой режим. Для полноценного прохождения нужно: после `wounded_scavenger_slain` и подбора клинка переключить `CombatController` в armed-режим (20 урона, `1H_Melee_Attack_Slice_Diagonal`, contact 0.4, cooldown 0.95). Это снимет проблему 24 ударов в E02. **P1, требует 04/06.**

## 6. Поведение и завершение столкновения

### 6.1. Реакции на урон и смерть

| Актор | Реакция | Когда | Ограничение |
|---|---|---|---|
| Санни | `Hit_A`/`HumanSpHeadHit` | любой урон вне атаки | не прерывает активный удар |
| Санни | `GUARD_HIT` | удар принят блоком | возвращает в стойку |
| Санни | `GUARD_BREAK` | stamina кончилась | стан 0.9 с |
| Тестовый враг | `Hit_A` | вне Telegraph/Attack | не сбивает замах |
| Карапакс | процедурный flinch | вне Telegraph/Attack/Death | 0.08 с назад + 0.16 с возврат |
| Личинка | squash scale | вне Telegraph/Attack/Death | 0.07 + 0.16 с |
| Горный Король | HitFlash | любой урон | нет stagger/knockdown |
| Все | Death | 0 HP | атака disabled, layer/mask 0, труп не блокирует |

Смертельный удар не запускает flinch: `HealthComponent.current_health` уже 0, а `died` проигрывает death-клип/тварь падает.

```
IDLE
  └─(цель в detection_range)→ CHASE
        ├─(дистанция ≤ attack_distance, cooldown готов)→ TELEGRAPH
        │       └─(telegraph_time)→ ATTACK
        │               └─(окно MeleeAttack закрылось)→ RECOVERY
        │                       └─(recovery_time)→ CHASE / IDLE
        ├─(цель ушла > lose_range / мертва)→ IDLE
        └─(нет продвижения)→ avoid → (3 раза)→ IDLE + 2 с cooldown
DEAD — финально; атака disabled, layer/mask 0
```

**Завершение:**

- Последний враг умер → `QuestKillCredit` ставит флаг → `CombatHud` через 2 с скрывает полосу → игрок может идти.
- Если игрок ушёл дальше leash → группа возвращается на спавн и снова спит (для `CombatEncounter`).
- Смерть игрока → `FallRecovery` возвращает на чекпоинт; живые карапаксы сбрасываются на полный HP и spawn, убитые не возрождаются (A05-04, Stage 3).
- Труп не блокирует маршрут; `collision_layer/mask = 0`.

## 8. Критерии приёмки

1. E01 проходится за 15–25 с, игрок понимает, почему получил урон.
2. E02 и E03 проходятся без зависаний и без одновременных трёх атак (после токенов).
3. Каждый удар попадает только в своём окне; повторного урона нет.
4. Смерть врага закрывает окно, отключает коллизию и квестовый кредит.
5. Смерть игрока возвращает на чекпоинт; удар снова работает.
6. HUD показывает HP/выносливость и цель; после боя скрывается.
7. Все атаки совпадают с видимым контактом (contact_time из клипа).
8. Нет врагов, застрявших в стене/на рампе.
9. Целевые GUT-тесты зелёные; полный GUT — после freeze.
10. Ручной проход E01–E03 записан в `docs/demo_sprint/qa/`.
