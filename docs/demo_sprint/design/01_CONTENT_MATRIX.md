## 7. Правило приоритета

1. Сначала — играбельный конец текущего milestone.
2. Затем — контент, который делает этот конец осмысленным (NPC, диалоги, цели).
3. Затем — модели, которые видны в кадре.
4. Затем — поздние локации.
5. Полировка — после стабильного прохождения.
