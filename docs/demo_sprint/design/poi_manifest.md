# POI Manifest — демонстрационный мир

**Автор:** Чат 03 — Lead World Designer / Level Designer  
**Дата:** 2026-11-02  
**Статус:** итоговый манифест точек интереса для M1 + tech demo. Игровые файлы не изменялись.  
**Связанные документы:** `world_layout.md`, `level_implementation_plan.md`, `side_quests.md`, `01_CONTENT_MATRIX.md`.

> **Координаты.** В городских сценах, академии, Чёрном море и спуске координаты **локальные для сцены**. В Лабиринте — мировые координаты `labyrinth_first_fragment`. `Y` — уровень пола/опоры; для маркеров, поднятых над полом, указано фактическое значение. Ориентация: `0°` — север (`−Z`), `90°` — запад (`−X`), `180°` — юг (`+Z`), `270°` — восток (`+X`).

**Статусы:**
- `EXIST` — узел уже есть в сцене.
- `RUNTIME` — создаётся `LabyrinthQuestDirector`/`QuestSystem` в runtime.
- `SQ` — точка из `side_quests.md`, ещё не реализована.
- `DESIGN` — проектная точка/объект.
- `FIX` — требует изменения геометрии или коллизии.
