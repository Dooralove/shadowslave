## 0. Правила статусов

| Статус | Значение |
|---|---|
| **PASS** | Проверка выполнена в этой сессии, результат воспроизводим, дефектов блокирующего уровня нет. |
| **PASS WITH LIMITATIONS** | Проверка выполнена, но есть известное ограничение, не ломающее демо-маршрут (визуал, звук, производительность, второстепенная система). |
| **FAIL** | Проверка выполнена, ожидаемое поведение не достигнуто. |
| **NOT VERIFIED** | Проверка не выполнялась или доказательство недостаточно (например, только отчёт другого чата). |
| **BLOCKED** | Проверку невозможно выполнить из-за отсутствующего пресета сборки, нестабильного дерева или незавершённой сцены. |

Правила:

1. Headless-тест не равен ручному прохождению.
2. Отчёт другого чата не является доказательством. Нужен запуск или запись в этой сессии.
3. Любой FAIL фиксируется с владельцем, файлами, точными шагами и ожидаемым результатом в `docs/demo_sprint/qa/QA_ISSUES.md`.
4. Нельзя помечать PASS пункт, который проверялся на другом коммите/грязном дереве без повторного прогона.
5. Скриншоты и логи — временные артефакты, если не указано иное. Пути в отчёте должны быть воспроизводимы.

- Acts C–D, западный город, полная академия, озвучка, лицевая анимация, кастомизация.

## 3. Критические маршруты

### CR-01 — Полный Первый Кошмар (P0)

Шаги:

1. Запустить `main_menu.tscn`; нажать «Играть».
2. Пройти B01–B16: кофе, сон, Code Black, изолятор, брифинг, видение, пробуждение, руны.
3. S01: марш в цепях, четыре знакомства, прибытие к лагерю.
4. S02–S06: паёк, Bloodbane, повозка, нападение, личинка, ключ, освобождение, клинья/петля, падение Тирана, последействие, три фляги, ветеран, Silver Bell, ночь, рассвет.
5. S07–S12: провал дороги, меч, альков, Шифти, Учёный, пещера, ранение, Герой, колокол, захват, храм.
6. S13: алтарь, семь подношений, Тиран, тени, завершение испытания.
7. S14: оценка, `glorious`, True Name, Aspect, Shadow Bond, First Seal.
8. S15: пробуждение, Flaw, финальная карточка, `R` → сброс в начало.

Критерии: нет падения, нет soft-lock, все гейты открываются, финальный флаг только в S15, повторный вход не дублирует награды.

### CR-02 — Пост-Кошмарная цепочка (P1)

`police_precinct → academy_approach → academy_gate → academy_campus → academy_sleeper_center → black_sea_platform → tide_descent → labyrinth_first_fragment`.

Проверить: вход из меню/финала, каждый портал, spawn, fade, цель на сцене, хотя бы одно взаимодействие, возврат/финал.

### CR-03 — Лабиринт, высокий маршрут (P1)

Z01 → Z03 → Z07 (гряда) → Z08 → Z10 (холм) → Z11 (верхний карниз) → Z12 → Z13 (северный траверс) → Z14 (костяной мост) → Z15 (убежище) → Z16 (южный гребень) → Z17 (верхняя тропа) → Z18 (утёсы).

Проверить: проходимость без обязательного прыжка/плавания, высокий путь всегда открыт, прилив не запирает, шторм не убивает без высокого обхода.

### CR-04 — Лабиринт, низкий риск/прилив (P1)

Z04 низина → Z05 костяной проход → Z06 сухой карман → Z08 → Z09 туннель → Z11 нижний порог (только отлив) → Z13 южный канал → Z14 низкая тропа → Z16 низ.

Проверить: закрытие низких маршрутов приливом, предупреждение за 30 секунд, выталкивание/чекпоинт вместо мгновенной смерти, возврат после смерти.

### CR-05 — Смерть и восстановление (P0)

Умереть в бою и упасть с высоты на ключевых сценах. Ожидание: чекпоинт/возврат, состояние квестов и инвентаря не теряется, награды не дублируются.

### CR-06 — Сохранение/загрузка (P1)

F5/F6 в кампании и Лабиринте: сохранить, изменить состояние, загрузить, проверить флаги/предметы/квесты/позицию. Повреждённый файл не должен ронять игру.

## 6. Bug severity и release gate

| Severity | Определение | Пример |
|---|---|---|
| **S0** | Демо нельзя запустить/пройти; потеря данных | краш на старте, soft-lock, финальный флаг не ставится |
| **S1** | Блокирует ключевую механику или маршрут, есть обход | мост не проходится, квест не завершается |
| **S2** | Заметный дефект, демо проходит | HUD показывает врага вне боя, текстура-заглушка |
| **S3** | Косметика/полировка | мелкий clip, неточная подпись |

Release gate для демо:

- нет открытых S0;
- S1 либо закрыты, либо явно приняты TD с обходом;
- полный GUT: 0 необъяснённых падений;
- импорт exit 0;
- CR-01 пройден вручную и записан;
- есть скриншоты ключевых сцен;
- экспорт либо PASS, либо **BLOCKED** с явной причиной (отсутствие пресета/шаблонов).

## 7. Доказательства

Для каждого прогона фиксировать:

- дату/время, HEAD, `git status --short` (число изменённых/untracked);

- для каждого FAIL — `QA_ISSUES.md` с owner/файлами/шагами/ожиданием.
