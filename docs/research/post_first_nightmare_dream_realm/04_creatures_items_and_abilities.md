# 04. Существа, предметы, способности и правила мира (главы 17–100)

**Статус:** заполнено по тексту зеркала WuxiaDreams (S-02) для глав 17–100. Главы 1–16 не проверены.
**Дата:** 2026-10-27
**Связанные документы:** [03_locations_and_world.md](03_locations_and_world.md), [02_character_dossiers.md](02_character_dossiers.md), [01_canonical_timeline.md](01_canonical_timeline.md), [05_scenes_and_dialogue_beats.md](05_scenes_and_dialogue_beats.md).

Метки: `TEXT` (прочитано в главе), `SEC` (вики), `INTERP` (интерпретация), `GAP` (не установлено), `GD` (предложение для геймдизайна, не канон). Ссылки «гл. N» — номер главы в S-02.

## 1. Правила мира (объективные, подтверждённые текстом)

### 1.1. Ранги людей
| Ранг | Как получают | Источник |
|---|---|---|
| Dormant (титул: Sleeper / Dreamer) | После Первого Кошмара | гл. 17, 22 `TEXT` |
| Awakened (титул: Awakened) | Выход через Врата в Царстве Снов; Аспект получает новую способность (у Санни — Shadow Step) | гл. 23 `TEXT` |
| Ascended (титул: Master) | После Второго Кошмара | гл. 17 `TEXT`; гл. 23 `TEXT` |
| Transcendent (титул: Saint) | После Третьего Кошмара | гл. 17 `TEXT`; гл. 81 `TEXT` (перечень рангов) |

Ранг и титул — разные поля данных: проверки читают ранг, интерфейс показывает титул (решение 2026-10-30).

### 1.2. Ранги Кошмарных созданий
- Dormant → Awakened → Fallen → Corrupted → Great → Cursed → Unholy (гл. 81). `TEXT`
- Классы по числу ядер: зверь (1), монстр (2), демон, дьявол (4 ядра у Великого Дьявола), тиран (5), ужас, титан (гл. 44, 81, 92). `TEXT` (перечень классов частично).
- Важно: в тексте класс и ранг различаются; «Великий Дьявол» — класс с четырьмя ядрами (гл. 81).

### 1.3. Врата, Цитадели, Царство Снов (гл. 23)
- Царство Снов — мир без сюжета; людей там нет, кроме пришедших; монстры могут имитировать людей. `TEXT`
- Выход — через Врата (Gateway) в Цитаделях или у главной достопримечательности региона; Врата дают статус Awakened и новую способность Аспекта. `TEXT`
- Смерть Sleeper в Царстве Снов не выпускает Кошмар в мир. `TEXT`
- Нет ограничения по рангу противника в Царстве Снов. `TEXT`

### 1.4. Memory и души
- Memory передаются только добровольно живым владельцем (касание; гл. 35, 54). `TEXT`
- Memory уничтожаются вместе с владельцем (гл. 35). `TEXT`
- Soul shards (кристаллы) — валюта Sleepers и основа роста ядра; поглощаются вручную (гл. 41, 51, 100). `TEXT`
- Shadow Fragments — рост Тени; берутся только при собственноручном убийстве: «спящее» ядро — 1, «пробуждённое» — 2 (гл. 34). `TEXT`
- Ядро Тени: усиливает Санни и Тень вместе (гл. 34). `TEXT`
- Echo — редкая награда за убийство Awakened-существа, может быть призвано (гл. 47). `TEXT`

### 1.5. Тенеобразные правила (Санни)
- Shadow Control: разделение с тенью, управление на расстоянии, ограниченный радиус (гл. 26, 31, 37, 62). `TEXT`
- Shadow Sight: восприятие через тень, видит в темноте (гл. 26, 37, 81). `TEXT`
- Тень усиливает предметы (оружие и броню), примерно вдвое относительно базы (гл. 28, 34). `TEXT`
- Тень не имеет материального тела (гл. 33–67): физический удар по ней не вредит (гл. 67). `TEXT`

### 1.6. Flaw Санни: Clear Conscience
- Нельзя лгать (гл. 17). `TEXT`
- Вопрос → пауза → давление → боль; формулировка ответа может быть искажена, но должна быть правдой (гл. 20, 21). `TEXT`
- Срыв при усталости и ментальном давлении (гл. 90). `TEXT`
- Ссылка на «Flaw» Нефис: боль при использовании Аспекта («как гореть заживо»; гл. 53). `TEXT`

### 1.7. Порча Древа Души (ментальная)
- Плоды Древа — ментальная порча и Shadow Fragments (гл. 77–78). `TEXT`
- Enthralled — атрибут-эффект порабощения (гл. 86). `TEXT`
- Doubtless (защита Puppeteer's Shroud) частично защищает от порчи (гл. 85). `TEXT`
- Ослабление с расстоянием от Древа: вывод Нефис (гл. 87). `TEXT` (логика персонажа)

## 2. Существа

### 2.1. Carapace Scavenger (Карапакс-мусорщик)
- **Внешний вид:** около 2–2,5 м; человеческий торс из панциря, четыре пары ног-серпов, две клешни вместо рук (гл. 31, 33). `TEXT`
- **Поведение:** стаи, поедание трупов; боятся крупных, избегают света (гл. 31, 40–41). `TEXT`
- **Слабые места (по Нефис):** сочленения; стык торса и панциря; тонкий участок на спине — смертельный удар (гл. 40). `TEXT`
- **Ранг:** Awakened (гл. 34). `TEXT`
- **Добыча:** кристалл (soul shard), Shadow Fragments при собственноручном убийстве (гл. 34, 41). `TEXT`
- **GD:** стандартный враг для тренировки стелса и добивания.

### 2.2. Carapace Centurion (Карапакс-Центурион)
- **Внешний вид:** крупнее скавенджера, ~3 м, шипы, косы вместо клешней (гл. 46–51). `TEXT`
- **Поведение:** охотится в одиночку; несёт трансцендентные кристаллы, похоже на ритуал (гл. 62). `TEXT`
- **Слабость:** щель между панцирем и торсом (гл. 51). `TEXT`
- **Смерть:** удар молнии в рукоять меча (гл. 52). `TEXT`
- **Ранг:** Awakened (гл. 52). `TEXT`
- **Добыча:** Memory Starlight Legion Armor (гл. 52). `TEXT`
- **GD:** босс-ловушка (верёвка на уровне ног, гребень).

### 2.3. Carapace Demon (Карапакс-Демон)
- **Внешний вид:** около 6–7 м; полированный металлический панцирь с семью звёздами на груди; четыре руки (две с клешнями, две с косами); рогатая голова (гл. 63, 66, 70). `TEXT`
- **Поведение:** разумный; ест плоды Древа (гл. 63); вступает в бой с монстрами моря (гл. 65, 69). `TEXT`
- **Слабость:** старый пролом брони на груди (гл. 65, 72). `TEXT` (видение Кассии)
- **Уязвимость к огню:** масло с огнём поджигает панцирь (гл. 69). `TEXT`
- **Смерть:** Нефис, Аспект в клинке, удар в грудь (гл. 72). `TEXT`
- **Добыча:** Memory Midnight Shard (гл. 74). `TEXT`

### 2.4. Echo — Carapace Scavenger (Эхо Санни)
- **Как получено:** Echo после убийства Awakened (гл. 47). `TEXT`
- **Атрибуты:** [Strong], [Armored]; ранг Awakened (гл. 47). `TEXT`
- **Функции:** переноска Кассии, отвлечение (гл. 47, 51, 66). `TEXT`
- **Смерть:** уничтожен Карапаксом-Демоном (гл. 67). `TEXT`
- **Возможность трансформации:** «превратить в Тень» — требуется 24/100 фрагментов (гл. 47). `TEXT` (не реализовано)

### 2.5. Центипеды-сколопендры
- **Внешний вид:** до 3 м, красный хитин, много ног (гл. 59). `TEXT`
- **Поведение:** быстрые, карабкаются по коралловым стенам, падают сверху (гл. 59). `TEXT`
- **Опасность:** едкая чёрная слизь (гл. 59). `TEXT`
- **Слабость:** хитин относительно тонкий, пробивается мечом (гл. 59). `TEXT`
- **Побочный продукт:** масляные мешки (два компонента; смешанный состав даёт едкое, горючее масло; гл. 59, 68). `TEXT`

### 2.6. Прочие существа лабиринта (гл. 59)
- Колонии червей под грязью; хищные «цветы» с вьющимися лозами; прозрачные щупальца, тащащие карапаксов в трещины. `TEXT` (описания без подробной механики.)

### 2.7. Крылатые твари (вороны / хищные птицы)
- **Внешний вид:** огромные, белое мускулистое тело, четыре-шесть лап, чёрные перья, клюв-ворон (гл. 53, 75). `TEXT`

### 2.8. Морские твари (щупальца, левиафаны, «гость из глубины»)

- **Гость из глубины (гл. 69):** бесформенная масса костей и водорослей, множество глаз; мимик голосов, вызывает панику. `TEXT`
- **Левиафан, чьи кости — Хребет (гл. 60):** `SEC`/`TEXT` (описание скелета).
- **Туманный силуэт (гл. 69):** в тумане за пределами видимости проступает фигура; конкретный облик не описан (`GAP`).

### 2.9. Soul Tree (Древо Души)
- **Внешний вид:** колоссальное дерево, чёрный ствол, красная листва, корни-кочки (гл. 61). `TEXT`

### 2.10. Great Devil (Великий Дьявол, «яйцо»)
