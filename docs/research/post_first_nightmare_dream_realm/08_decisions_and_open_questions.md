## 1. Ответы разработчика

### Q1. Где размещается игровой сегмент?
- **Ответ:** одна сюжетная кампания. Пробуждение в полицейском участке сразу после финала первого Кошмара, полная арка Академии, затем Царство Снов. Ничего не вырезается.
- **Принятое решение:** продолжение кампании, Академия — полноценный игровой материал.
- **Влияние на геймплей:** блоки P01–P09 (гл. 17–29) входят в сегмент.
- **Последствия для канона:** порядок событий сохраняется полностью (гл. 17 → 29 → 30).
- **Требования к реализации:** переход из финала первого Кошмара в участок; сохранение `NightmareRunState` без сброса; блоки полиции и Академии.
- **Документы для обновления:** 07 (уже обновлён), README (обновлён).

### Q2. Насколько самостоятельны Нефис и Кассия?
- **Ответ:** Нефис — полноценный напарник, сама сражается и двигается, игрок ею не управляет (аналогия: Весемир в бою с грифоном в «Ведьмаке 3»). Кассия — в бою не участвует; в фоне предупреждает о нападениях (в том числе со спины) и даёт подсказки, двигает сюжет. Боевая роль Кассии — позже, не сейчас.
- **Принятое решение:** Нефис — автономный боевой спутник без команд. Кассия — вспомогательный персонаж без боевого участия.
- **Влияние на геймплей:** Нефис меняет тактику боя (приманка и добивание без команд). Кассия не получает и не наносит урона в бою; её предупреждения — сигнал игроку (звук, подсветка, реплика).
- **Последствия для канона:** канон сохраняется (гл. 35–95).
- **Требования к реализации:** ИИ Нефис (приманка, добивание, укрытие); сценарные триггеры предупреждений Кассии.
- **Документы для обновления:** 07 (блоки B04–B06, B08, таблица систем), 02 (роль Кассии).
- **Подтверждено 2026-10-30:** отряд — автономные временные союзники: появляются и уходят по сюжету, команд нет. Смертельный удар наносит тот, кто успел; фрагменты Санни получает только за свои убийства.
- **Дополнено 2026-10-30 (`14` §2.3):** мягкая синергия без команд — удар Нефис, оглушивший врага, открывает Санни добивание (на ~2 с `PRELIM` она переключается на другую цель); метка Санни — её предпочтение, не приказ.

### Q3. Насколько широко используется Flaw в диалогах?
- **Ответ:** отдельной диалоговой системы нет. Реплики берутся из канона. Механика формулировки — только в ключевых сценах (интервью в Академии, разговор с Нефис в лабиринте и похожие).
- **Принятое решение:** вариант «только ключевые сцены».
- **Влияние на геймплей:** почти все диалоги линейны; в ключевых сценах игрок выбирает формулировку.
- **Последствия для канона:** см. U2 — выбор не меняет сюжет.
- **Требования к реализации:** список из 2–3 вариантов формулировок для каждой ключевой сцены. Флаг выбора заводится только там, где его читает следующая сцена (2026-10-30). Ключевые сцены — сцены-дуэли (3–5 на акт): шкала живёт только внутри сцены, наружу выходит один итог-флаг (`14` §2.4).
- **Документы для обновления:** 05 (пометка «Flaw-выбор» у ключевых сцен), 07, 04.

### Q4. Смерть и чекпоинты.
- **Ответ (2026-10-27):** возврат к последнему сохранению (как в «Ведьмаке»). Потеря теней или кристаллов душ пока не вводится; идея отложена.
- **Пересмотрено 2026-10-30 (аудит `13`, Д1):** прежнее решение вместе с `12` §13.6 («мета-прогресс не откатывается») давало дюп предметов после загрузки. Принят персистентный мир.
- **Принятое решение:** смерть возвращает Санни к последнему привалу в том же мире. Убитые враги остаются мёртвыми, найденное остаётся при нём, потраченные расходники не возвращаются, аптечка пополняется у привала. Потери теней и кристаллов нет.
- **Влияние на геймплей:** цена смерти — время, позиция и потраченные ресурсы, но не билд и не находки.
- **Последствия для канона:** нет.
- **Требования к реализации:** живые враги после смерти Санни возвращаются на места с полным здоровьем `PRELIM`, бой с боссом начинается заново; у боссов — источники нужных расходников (защита от софтлока); вне сохранения живут только настройки, достижения и косметический кодекс. Сценарные чекпоинты Первого Кошмара (раздел 0) не меняются. См. U3.
- **Документы для обновления:** 07, 09, 11, 12 (обновлены 2026-10-30), README.

### Q5. Структура пространства.
- **Ответ:** полуоткрытый лабиринт.
- **Принятое решение:** полуоткрытые зоны с ориентирами (статуя, курган, тень Шпиля, кость-хребет) и несколькими путями.
- **Влияние на геймплей:** исследование внутри зоны, без свободных перемещений между зонами.
- **Последствия для канона:** совпадает с каноном (лабиринт запутан, ориентиры описаны).
- **Требования к реализации:** карта-ориентир, маркеры, несколько путей в каждой зоне.
- **Документы для обновления:** 03, 07.

- **Принятое решение:** сегмент заканчивается на главе 95.
- **Документы для обновления:** 07, README (обновлены).

## 2. Уточнения разработчика

### U1. Может ли Кассия получать урон в бою?
- **Ответ:** нет. Кассия урон по бою получать не может.
- **Принятое решение:** Кассия неуязвима в бою (вариант A из предложенных).
- **Влияние на геймплей:** провала по её вине в бою нет; её предупреждения — только информация.
- **Последствия для канона:** канон не меняется (Кассия в бою не сражается; опасность передаётся через Санни и Нефис).
- **Документы для обновления:** 07 (блок B09: «Нефис атакует» — без урона Кассии; таблица систем), 02.

### U2. Что даёт выбор формулировки в ключевых сценах?
- **Ответ:** выбор формулировки почти ни на что не влияет. Не более чем косметические изменения поведения и реакций персонажей. Основная логика строится на книжном повествовании, которое нельзя изменить; реальных развилок в сюжете не будет.
- **Принятое решение:** выбор формулировки не влияет на сюжетные события. Допустимы только косметические реакции (тон, мимика, короткие реплики собеседника).
- **Влияние на геймплей:** ключевые сцены с Flaw-выбором остаются линейными по итогам; выбор даёт ощущение участия, но не меняет исход.
- **Последствия для канона:** сюжет не ветвится; канон сохраняется полностью.
- **Требования к реализации:** для каждой ключевой сцены — набор реакций собеседника на выбранную формулировку (косметика). **Уточнено 2026-10-30:** флаг выбора заводится только там, где его читает следующая сцена; общей системы подозрения и доверия нет.
- **Документы для обновления:** 05 (пометить Flaw-выбор как косметический), 07 (B04, P04, P06), 08 (раздел 3 — уточнение).

### U3. Тип сохранений.
- **Ответ (2026-10-27):** оба варианта — ручные сохранения и автосохранения.
- **Пересмотрено 2026-10-30** вместе с Q4.
- **Принятое решение:** автосохранение на привалах и ручные сохранения игрока. Смерть **не** загружает сохранение: Санни возвращается к последнему привалу в текущем мире (Q4).
- **Влияние на геймплей:** ручное сохранение — слот для выхода из игры; его загрузка откатывает всё состояние, включая предметы и фрагменты.
- **Последствия для канона:** нет.
- **Требования к реализации:** сохранение — полный снимок состояния; реестра наград вне снимка нет.
- **Документы для обновления:** 07 (раздел 4, таблица систем), README.
