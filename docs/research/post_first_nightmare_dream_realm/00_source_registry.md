# 00. Реестр источников

**Статус:** частично выполнен (этап 2, проверка 2026-10-27)
**Дата:** 2026-10-27
**Связанные документы:** [01_canonical_timeline.md](01_canonical_timeline.md)

## Статусы

| Статус | Значение |
|---|---|
| `VERIFIED` | Проверено по первоисточнику (сам текст главы открыт и прочитан) |
| `PARTIAL` | Проверено частично: только оглавление, заголовок, короткий фрагмент или пересказ вторичного источника |
| `CONFLICT` | Источники противоречат друг другу |
| `UNVERIFIED` | Пока не подтверждено |

Дополнительно: **INTERPRETATION**, **FAN THEORY**, **SECONDARY-ONLY** (известно только из вторичного источника; в тексте первоисточника не сверено).

## Ограничение доступа (главное)

- WebNovel (официальная площадка автора): страницы глав отдают HTTP **403** на автоматические запросы. Не открыт.
- Fandom-вики (`shadowslave.fandom.com`): HTTP **402**. Не открыт.
- WuxiaDreams (зеркало): страницы глав открываются в браузерной панели. Главы **17–29 прочитаны полностью**, глава 30 — до конца первой сцены.

Статус `TEXT` означает «прочитано по зеркалу WuxiaDreams», а не «сверено с WebNovel». Сверка с первоисточником остаётся открытой. Вики-утверждения (Miraheze) по главам 1–16 и по томам остаются `PARTIAL` или `SECONDARY`.
