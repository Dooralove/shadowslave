**Статус:** исследовательский этап завершён (документация и план). Godot не менялся. Коммитов не было.
**Дата:** 2026-10-27

## 1. Границы

- **Старт:** сразу после финала первого Кошмара — пробуждение в полицейском участке (гл. 17). Конец главы 16 — граница пробуждения (подтверждено по тексту).
- **Далее по канону:** полная арка Академии (гл. 18–29), Царство Снов (гл. 30–95).
- **Конец игрового сегмента:** выход из моря к стене города (гл. 95).
- **Вне сегмента:** город (гл. 96–100) — изучен по тексту, но не входит в план.

## 3. Подтверждённые источники

- **Основной текст:** зеркало WuxiaDreams (S-02). Главы 16–99 прочитаны, глава 100 — частично. Главы 8, 15, 16 проверены отдельно. Главы 1–7, 9–14 — не проверены.
- **WebNovel (первоисточник):** 403 на автоматический доступ. Ни одна глава не сверена с ним.
- **Вики (Miraheze):** используется только для контроля и помечено как `SEC`.
- **Манга / манхва / аниме:** подтверждённых глав нет (вебкомикс и аниме анонсированы).

## 4. Значимые пробелы

1. **Главы 1–16** не проверены по тексту (кроме 8, 15, 16).
2. **Сверка с WebNovel** не выполнена; объём новеллы (CONFLICT-01) открыт: зеркало 2720 глав, сниппет — более 3090.
3. **Слова «Aster / Song / Vale» и слово «пять»** (гл. 75, 84, 88, 91) — смысл не раскрыт; влияет на блоки B09–B10.
4. **Облик «гостя из глубин»** (гл. 69) и «центуриона с двумя тенями» (гл. 66) — не описаны в тексте.
5. **Ранг Карапакса-Демона и Чёрного Рыцаря** — не назван в тексте.
6. **Причина разрыва Санни и Нефис** в замке и **судьба Кассии** после замка — косвенные указания (вне сегмента).
7. **Внутренние расхождения текста:** Shadow Fragments после плодов Древа (гл. 81); срок на острове (гл. 77–85).

## 5. Решения разработчика (зафиксированы в 08)

- Одна сюжетная кампания: полиция → полная Академия → Царство Снов.
- Нефис — автономный боевой спутник, без управления игроком.
- Кассия — без боевого участия; фоновые предупреждения и подсказки; двигает сюжет.
- Flaw-механика диалогов — только в ключевых сценах; остальные реплики линейны, из канона.
- Смерть — возврат к последнему сохранению; потеря ресурсов отложена.
- Пространство — полуоткрытый лабиринт с ориентирами.
- Конец сегмента — выход к стене города (гл. 95).

## 6. Что ещё требует решения

Геймдизайнерских вопросов нет. Все U1–U3 закрыты: Кассия неуязвима в бою; выбор формулировки косметический и сюжет не меняет; сохранения — ручные и автосохранения.

Открыты только вопросы к тексту (см. 08, раздел 4).
