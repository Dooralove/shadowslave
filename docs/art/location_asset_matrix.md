Дата: 2026-10-26. Ветка `s3-park-art`. Документ ведётся по мере производства: статусы ниже —
фактические на дату. Стандарт производства — `docs/art/asset_production_standards.md`.

## Обозначения

| Метка | Значение |
|---|---|
| **CANON** | Прямо подтверждено текстом романа (главы указаны; по документам исследований проекта) |
| **CANON-INFERRED** | Разумный вывод из канона, не прямое утверждение текста |
| **ART-DIRECTION** | Художественное решение там, где канон молчит; не выдаётся за канон |
| Группа | A — ключевые объекты, B — модули, C — природа, D — реквизит, E — специальные объекты |
| Приоритет | P0 — нужен для читаемости локации; P1 — заметно улучшает; P2 — дополнение |
| Статус | отсутствует → в производстве → создан → экспортирован → **проверен** (импорт Godot + превью) |

### Противоречия в документах и принятое решение

1. **Архитектура храма.** `ancient_ruins_architecture_style.md` описывает циклопическую сухую кладку
   без колонн и прямо пишет, что канонического описания не нашёл. Глава 14 (через
   `canon_shadow_shrine.md` и `level_brief_shadow_sanctuary.md`) — **CANON**: колоссальные колонны и
   стены из чёрного мрамора, изысканные рельефы на фронтоне и широком фризе, «дворец тёмного бога».
   Решение: форма храма — по главе 14; из стиля руин берутся только язык разрушения, приёмы
   рельефа (геометрия, безликие фигуры) и материал-логика — как **ART-DIRECTION**.
2. **Алтарь.** Стиль руин: 1,4–1,9 м высотой («по грудь»). Канон гл. 14: «широкий, как кровать»,
   Санни сам на него ложится → низкая плита ~2,4 × 1,2 × 0,9 м (бриф святилища). Принят канон.
   Текущий CSG-алтарь `shadow_sanctuary.tscn` (подиум + монолит 1,5 × 1 × 1) и механика «семи
   подношений» — игровая адаптация проекта; замена геометрии — отдельная работа (не в этой партии).
3. **Стороны дороги.** Гл. 2: скала справа, бездна слева. Бриф тропы зеркалит. Модули сделаны по
   канону; зеркальная раскладка — поворот модуля на 180° (gap matrix: «в новых сценах — канон»).
