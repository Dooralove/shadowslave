# Стандарт производства 3D-ассетов окружения

Дата: 2026-10-26. Действует для окружения Первого Кошмара (`assets/environments/nightmare/`) и
всех новых ассетов окружения. Не отменяет решений S3.1–S3.2 по парку (`docs/DECISIONS.md`):
стандарт обобщает их конвейер (скрипт Blender → `.glb` → внешние материалы `.tres`).

Карта локаций и статусов — `docs/art/location_asset_matrix.md`.

## 1. Инструменты и воспроизводимость

- **Blender 5.1** (установлен у пользователя), сборка скриптами Python в фоне:
  `blender -b --factory-startup --python <скрипт> -- [опции]`. Скрипт — источник правды;
  `.blend` — сохранённый результат для правки и просмотра.
- **Blender MCP** подключён, но работает в безопасном режиме (без импорта своих модулей и чтения
  файлов) — годится для осмотра сцены, а не для сборки. Сборка и превью — фоновым Blender.
- **Общий код**: `source/nm_lib.py` (генераторы, маски, коллизии, экспорт, превью),
  `source/nm_materials.py` (материалы — одно описание для Blender и Godot),
  `source/make_nm_textures.py` (производные текстуры), `source/make_godot_materials.py` (`.tres` и
  привязка слотов). Сборщики партий — `source/build_<партия>.py`.
- Детерминизм: все случайные величины — от фиксированных `seed`. Повторная сборка даёт те же меши.

## 2. Структура папок

```
assets/environments/nightmare/
  source/        build_*.py, nm_*.py, *.blend (исходники; .blend — Git LFS)
  materials/     *.tres (Godot), nm_layered_triplanar.gdshader
  materials/textures/   текстуры CC0 и производные (JPEG, Git LFS)
  mountain/      .glb горного набора (партия 1)
  caravan/  remains/  flora/  temple/  trail/   .glb следующих партий
assets/environments/prologue/  второе семейство (пролог): source/ (build_prologue_kit.py, pr_materials.py,
  make_pr_textures.py, prologue_kit.blend), materials/pr_*.tres + textures/, cell/, lobby/
assets/environments/park/props/  модели парка (S3.2 + деревья и фонарь партии 5), материалы — park/materials/
docs/art/previews/nightmare/, docs/art/previews/prologue/   превью-рендеры Cycles (JPEG, Git LFS, .gdignore)
```

Новое семейство ассетов не заводит свои инструменты: материалы — модулем по образцу `nm_materials.py`,
регистрация в Blender — `nm_lib.register_materials(MATERIALS, TEXSETS, папка_текстур)`, Godot —
`make_godot_materials.py --family <имя>` (семейство описывается в `FAMILIES`).

Один `.blend` на семейство (горный набор, реквизит каравана, храм), не на каждый камень и не на весь мир.
Внутри: коллекция `ASSETS` (исключена из слоя) → по коллекции на ассет, все в начале координат;
коллекция `PREVIEW` — экземпляры коллекций, разложенные для осмотра, камера, свет, манекен 1,75 м.
Чтобы править ассет — включить его коллекцию в `ASSETS`.

## 3. Масштаб, оси, опорные точки

- 1 единица = 1 м. Эталон масштаба — манекен 1,75 м (Санни ≈ 1,65–1,68 м, канон: ниже окружающих).
- Blender: вверх +Z, вперёд по маршруту +Y. Экспорт glTF с `+Y up` → в Godot вперёд = −Z.
- Опорные точки:
  - валуны, реквизит — центр основания, низ слегка утоплен (камни 8–30 см «вросли» в снег);
  - скальные стены — основание лица стены на дороге: лицо около `x = 0`, тело в +X, низ −0,6 м,
    длина модуля по +Y с нахлёстом ±0,4 м (ставятся встык с шагом 6 м, нахлёст прячет шов);
  - кромки обрыва — край дороги: тело в −X, верх −0,05 м под полотном, шаг 5 м;
  - модули дороги — центр полосы в начале модуля, верх полотна `z = 0`, длина 4 м по +Y.
- Канон гл. 2: скала справа, бездна слева. Модули построены так; зеркальная раскладка брифа
  тропы — поворотом модуля на 180° вокруг вертикали (не отрицательным масштабом).
- Трансформации применены: у объектов в `ASSETS` нулевые вращение/масштаб (кроме наборов, где
  части нарочно разнесены по X — см. каталог).

## 4. Геометрия и качество формы

- Силуэт и крупная форма важнее мелочи. Камень: крупные плоскости раскола, уступы, трещины-
  отдельности; не равномерная «чешуя» шума (бриф тропы, §8; стиль руин, §3).
- Вариации — разные силуэты и способы образования (окатанный, свежий скол, плита, зуб, раскол,
  выход породы), а не масштабные копии.
- Камень: выпуклые «сколы» + слияние вокселями + выветривание + прореживание (Decimate Collapse).
  Скальные стены: лицо из граней по ячейкам Вороного, вытянутым по напластованию, + блоки-контрфорсы.
- Мощение: ячейки Вороного; концевые полосы сайтов общие для всех вариантов → любые модули
  дороги стыкуются без шва; шум поверхностей периодичен по длине модуля.
- Нормали: гладкое затенение + острые рёбра по углу (40–70° в зависимости от типа).
- Меш замкнут там, где участвует в тенях и вокселях; невидимый тыл стен срезан плоскостью.
- Ориентиры сложности (не жёсткий бюджет; Godot строит LOD сам при импорте):

| Тип | Треугольники |
|---|---|
| Обломок, мелкий реквизит | 0,2–1 тыс. |
| Валун, надув | 1–3 тыс. |
| Модуль дороги (4 × 2,5 м) | 5–8 тыс. |
| Модуль кромки (5 м) | 6–8 тыс. |
| Скальная стена (6 × 12 м) | 7–9 тыс. |
| Герой-объект (повозка, алтарь) | 5–20 тыс. |
| Дальняя гора | 24–40 тыс. |

## 4а. Твёрдые поверхности (пролог)

- Деталь — отдельный объект: UV-проекция в метрах, затем Bevel (ограничение по углу 35°, 1–3 сегмента,
  `harden_normals`), применение; детали ассета сливаются `join` (сохраняет заданные нормали фасок).
  `merge_objects` (bmesh) для таких деталей не годится — стирает нормали.
- Фаска — по масштабу детали: плиты брони 15–25 мм (1 сегмент — «рубленая» кромка), панели 8–12 мм,
  крепёж и мелочь 2–6 мм, мягкие накладки 25–30 мм в 3 сегмента.
- Узлы, которыми сценарий может управлять (индикатор Заклятия, статусные огни, рассеиватели), — отдельные меши
  с понятными именами, а не поверхность общего меша.
- Модули помещений: лицо в −Y, тело в +Y, начало — низ лица по центру; потолочные — начало на плоскости потолка,
  настенные мелочи — на плоскости стены.

## 5. Материалы и текстуры

- Слоты материалов в `.glb` — по именам `nm_*` из `nm_materials.py`; картинки в `.glb` не
  встраиваются (`export_image_format = NONE`). В Godot слоты подменяются внешними `.tres`
  через `.import` (`_subresources/materials/<слот>/use_external`) — как у скамейки парка.
- Два вида материалов:
  - **layered** (порода, обработанный камень, снег, лёд, чёрный мрамор, кость) — шейдер
    `nm_layered_triplanar.gdshader`: трипланар в координатах объекта (с учётом масштаба экземпляра),
    снег по мировой нормали «вверх», грязь/AO и склонность к снегу из цвета вершин;
  - **uv** (дерево, железо, ткань, кожа) — `ORMMaterial3D` по UV в метрах, цвет вершин умножает альбедо.
- Цветовой атрибут `nm_mask` (float, линейный, экспорт COLOR_0): RGB — AO самозатенения
  (лучи по BVH), затемнение основания, лёгкая вариация тона; A — склонность к снегу
  (0 под навесами). Без атрибута шейдер считает его белым.
- UV: у всех мешей — кубическая развёртка в метрах (для лайтмапов и UV-материалов).
- Текстуры — CC0 Poly Haven (реестр — `docs/ASSET_LICENSES.md`) и производные альбедо
  (`make_nm_textures.py`): перекраска под палитру брифа перевала, процедурный чёрный мрамор.
  2K — большие поверхности (камень, снег, мрамор), 1K — реквизит. Нормали — RGTC
  (`compress/normal_map=1`), высоты и заменённые исходные альбедо — `importer="skip"` (нужны только Blender).
- Пути только относительные: `.blend` хранит `//../materials/textures/...`, `.tres` — `res://`.

## 6. Коллизия

- Отдельные простые меши с суффиксами Godot: `-convcolonly` (выпуклая оболочка ≤ 64 вершин —
  валуны, надувы, осыпь), `-colonly` (прореженная копия 200–600 треугольников — стены, кромки,
  выходы породы; ящик или профиль — модули дороги, уступ — пандусом).
- Мелкие обломки и малые надувы — без коллизии.
- Помещения (пролог): стенные модули, пол, потолок, короба дверей, стойки — ящики `-colonly`; дверной проём
  свободен, полотно двери — своя коллизия; потолочные и настенные мелочи (турели, светильники, решётки) — без коллизии.
- Коллизия дороги — ровная плоскость верха полотна (`z = 0`), чтобы контроллер не цеплялся за плиты.

## 7. Экспорт и импорт

- Одна коллекция → один `.glb` (`export_collection` в `nm_lib.py`): `export_apply`, `+Y up`,
  нормали, COLOR_0, без камер и света.
- Импорт Godot: параметры по умолчанию, как у ассетов парка (LOD и тени генерируются).
  После первого импорта — `make_godot_materials.py --bind`, затем повторный импорт.
- Проверка: `godot --headless --path . --import` без ошибок в выводе; превью-сцена
  `scenes/dev/nightmare_asset_preview.tscn` — кадр из Godot.

## 8. Превью и приёмка

- Превью — Cycles, AgX, холодное небо + низкое солнце (15–25°, как в брифе перевала), манекен 1,75 м.
  Для модулей — сборка встык и кадр с высоты глаз (1,6 м).
- Ассет считается **проверенным**, если: есть исходник (`.blend` + скрипт), `.glb` экспортирован,
  импорт Godot без ошибок, материалы привязаны, есть превью Blender и кадр из Godot, масштаб
  сверен с манекеном. Статусы — в `location_asset_matrix.md`.
- Чек-лист:
  - [ ] силуэт читается без текстур, вариации различаются формой;
  - [ ] масштаб относительно манекена правдоподобен;
  - [ ] опорная точка и оси по §3; трансформации применены;
  - [ ] нет висящих/торчащих частей, коллизия есть там, где нужна;
  - [ ] материалы — только слоты `nm_*`, пути относительные, внешних файлов не потеряно;
  - [ ] в коллекции нет лишних объектов (только визуальный меш и коллизия);
  - [ ] превью сохранено, ассет внесён в матрицу.
