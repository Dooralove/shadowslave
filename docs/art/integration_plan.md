# План интеграции 3D-окружения в сюжетные сцены

Дата: 2026-10-26. Ветка `s3-park-art`. Ассеты и статусы — `docs/art/location_asset_matrix.md`;
стандарт — `docs/art/asset_production_standards.md`. Этот документ — порядок встраивания и его состояние.

## 1. Принципы (по решению S3.1 для парка)

- **Вариант без правки сценария.** Арт-версия локации — сцена-наследник (`<локация>_art.tscn`): прячет CSG-геометрию,
  выключает её коллизию, добавляет модели. Скрипт локации, `Spawns`, `Interactables`, `Triggers`, ID постановок
  не меняются. Переопределяются только позиции сценических узлов, которые физически оказались внутри новой
  геометрии (ракурсы `Shots/*`, посты манекенов, `Markers/*`), — каждое такое переопределение перечислено ниже.
- **Подключение — через `SliceDirector.location_overrides`** в корне `scenes/slice/locations/park/prologue_park_art.tscn`
  (арт-пролог). Основной пролог `scenes/slice/prologue.tscn` и кампания (`campaign_entry.tscn` → `prologue.tscn`)
  переключаются только после визуального одобрения пользователем (как и решено для парка в S3.1).
- **Узлы, которыми управляет сценарий, остаются теми же.** Новые модели вешаются внутрь них: дверь — в
  `Geometry/DoorPivot` (его поворачивает постановка), ремни — в `Chair/Restraints` (их показывает постановка).
- **Проверка каждой группы:** импорт без ошибок; тест варианта (игровые точки не сдвинуты, CSG скрыт и без
  коллизии, модели на местах, ракурсы смотрят на `LookAt`); прогон арт-пролога (`test_park_art`); кадры из Godot.
  Полный сквозной прогон кампании — только после завершения интеграции всех групп.

## 2. Пролог (L01–L03) — выполняется в этой работе

### 2.1 Изолятор: `containment_room.tscn` → `containment_room_art.tscn`

Расхождения CSG и брифа: комната 7,8 × 7,8 м (бриф — 3,6 × 4,4 × 2,45), дверь в 3,7 м от центра, коридор до −10 м,
посты охраны на ±2,4 м (за стенами нового бокса), ракурсы снаружи бокса, сидячий стул (поза `Sitting_Idle`),
дверь открывается внутрь (`rotation.y = −1,6`) со штурвалом со стороны камеры.

| Решение | Почему |
|---|---|
| Бокс по брифу, центр по X — на оси `Spawns/Chair` (x = 0), дверная стена — z = −1,25, дальняя — z = +3,15 | Точка появления Санни не двигается; ось двери совпадает с коридором |
| Кресло — вариант `restraint_chair_upright` (под позу `Sitting_Idle`, замер костей в Godot), в `Chair` | Полулежачее кресло брифа требует новой анимации; без неё поза пересекала бы спинку |
| Ремни — `restraint_chair_upright_straps` в `Chair/Restraints` | Постановка `restrain` делает этот узел видимым |
| Дверь — `vault_door_inward` в `Geometry/DoorPivot`, ось петель — на оси вращения | Постановка открывает дверь внутрь; упор, штурвал и петли — со стороны бокса, как штурвал CSG |
| Коридор — прежний CSG, сдвинут к новой двери (z −1,5…−7,5), полицейский стартует на −6,5 | Коридор в брифе не описан; модели коридора нет |
| `Markers/ChairFront` → (0,45; 0; −0,4) | Прямой путь полицейского к старой точке проходил сквозь откос двери шириной 1,12 м |
| Посты охраны → (∓1,45 / 1,35; 0; −0,65), повороты прежние | Старые посты за стенами бокса |
| `Shots/RoomShot` → у купольной камеры (1,42; 2,2; 2,8), `DoorShot` — без изменений | Старая камера снаружи бокса |
| Свет: `Overhead` → под светильником (0; 2,35; 1,3), `Fill` → (0; 2,3; −0,6), `CorridorLight` → (0; 2,3; −4,5) | Старые точки выше нового потолка |

### 2.2 Лобби: `station_lobby.tscn` → `station_lobby_art.tscn`

| Решение | Почему |
|---|---|
| CSG-плиты, стойка, терминал, турели, световые панели и входная дверь скрыты; стены, пол, потолок и боковые двери CSG остаются с материалами пролога (трипланар) | Модели стен лобби нет и канон их не описывает; плиты закрывают стены |
| Плиты: север — a / b / b / b / a; запад и восток — a, a, b | Канон «бронеплиты на стенах»; места CSG-плит сохранены, промежутки закрыты узкими плитами |
| `desk_counter` и `terminal_desk` на местах CSG (стойка у z = −3) | `Spawns/Counter` (z = −1,9) остаётся перед ступенькой посетителя |
| Турели в трёх углах; в юго-восточном — нет | `Shots/AlarmShot` стоит в этом углу (взгляд из гнезда); модель закрывала бы кадр |
| Вход: `door_station_entrance` + вырез проёма в CSG-стене (дочерний CSG-вычитатель) | У CSG-стены нет проёма; створки иначе оказались бы внутри стены |

### 2.3 Парк: `park_art.tscn` (уже арт-сцена S3.1)

| Решение | Почему |
|---|---|
| Узлы блок-аута `Planter*`, `Trunk*`, `Crown*`, `LampPole*`, `LampHead*`, `ArmorPanel*`, `SlitWindow*`, `Entrance*`, `Door`, `Canopy`, `Bollard*` скрыты; их коллизии остаются (совпадают по месту с коллизиями моделей) | Не трогать `park_blockout.glb` (S3.1); прятать — обратимо |
| Деревья `tree_planter_a/b/c`, фонари `lamp_street_a`, столбики `bollard_a` — по точкам блок-аута, масштаб 1 | Кадки моделей = кадки блок-аута 1,3 м, коллизии совпадают |
| Фасад: модули `station_facade_bay` / `station_facade_slit` на лице объёма (z = −19), вход `station_entrance` | Сохраняются объём, цоколь, табличка `Label3D` и свет входа |

Замеченные ограничения:
- основной пролог играет моделью KayKit: её голова проходит сквозь полукожух кресла, стопы висят над манжетами
  (кресло снято с позы POC; `main_cell_kaykit.jpg`);
- кресло брифа `restraint_chair` (полулёжа) в сцену не поставлено: нет позы; поставлен вариант под `Sitting_Idle`;
- стекло бокса смотрит в тусклый пост наблюдения (CSG-коробка с огнём) — модели поста нет, бриф его не описывает;
- коридор за дверью бокса и боковые двери лобби — по-прежнему CSG (с новыми материалами).
